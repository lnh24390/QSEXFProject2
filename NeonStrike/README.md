# NEON STRIKE

브라우저 레이캐스팅 방식으로 제작된 팀 기반 FPS 게임입니다. 멀티플레이 로비, 봇전, 과녁 훈련장, 6개의 전장, 3종 소총과 Windows 실행 파일을 제공합니다.

## 빠른 실행

Windows에서는 루트 폴더의 `NeonStrike.exe`를 실행하세요.

- Microsoft Edge 전체화면 키오스크 모드로 실행하여 작업표시줄 숨김
- EXE와 작업표시줄에 소총 실루엣 아이콘 표시
- 별도 설치 과정과 외부 게임 서버 불필요
- Microsoft Edge가 설치되어 있어야 함

브라우저에서 직접 실행하려면 `dist/index.html`을 열거나 정적 서버를 사용할 수 있습니다.

```powershell
python -m http.server 8080 --directory dist
```

실행 후 `http://localhost:8080`에 접속합니다.

## 게임 모드

### 멀티플레이

- 방 만들기, 빠른 시작, 방 코드 참가 및 방 목록 지원
- 메인 로비와 일반 대기방의 총 선택 제거
- 방장 START 후 1분 동안 전용 총 선택 화면에서 K2 / AK-47 / M16 선택
- 총 선택 버튼에 K2 / AK-47 / M16의 측면 디자인 표시
- 캐릭터 선택창 스타일의 전용 화면에 큰 총 디자인, 무기 특성, 피해량·연사속도·탄창 표시
- 아군 선택 현황과 남은 시간을 표시하고, 시간 종료 시 선택한 총 자동 적용
- 대기방에서 선택한 총은 참가자 명단, 로딩 화면과 실제 경기에 반영
- 경기 전 총 변경은 START 후 선택 시간에만 가능하며 준비 상태 유지
- 상대 팀의 총 정보는 대기방, 로딩 화면과 점수판에서 숨김
- 팀 선택은 방 입장 후 대기방에서 진행
- 대기방의 `BLUE TEAM` / `RED TEAM` 버튼으로 팀 변경 가능하며 다른 참가자에게 즉시 반영
- 팀 변경 시 준비 상태가 해제되고 진행 중인 시작 카운트다운 취소
- BLUE 5명 / RED 5명, 방당 최대 10명 참가 가능
- 신규 방은 입장 순서대로 BLUE → RED → BLUE → RED 교대 배정
- 퇴장이나 팀 변경으로 인원 차이가 생기면 인원이 적은 팀부터 배정
- 팀 변경 후 인원 차이는 최대 1명이며, 경기 재시작 시 선택한 팀 유지
- 5명이 찬 팀으로 변경할 수 없으며, 10명이 찬 방은 추가 참가 불가
- BLUE / RED 인원이 같아야 준비 및 경기 시작 가능 (1대1부터 5대5까지)
- 전원 준비 후에도 팀 인원이 달라지면 시작 카운트다운 취소
- 대기방 플레이어 목록을 BLUE TEAM / RED TEAM 영역으로 분리하고 팀별 인원수 표시
- BLUE는 파란색, RED는 빨간색 테두리·배경·팀 라벨로 구분
- 내 팀에는 `MY TEAM`, 내 플레이어에는 `(YOU)`와 강조 테두리 표시
- 팀에 참가자가 없으면 빈 팀 안내 표시
- 방장에게는 `START` 버튼만 표시되며, 나머지 참가자는 `READY` / `NOT READY`만 사용 가능
- 두 팀 인원이 같고 방장을 제외한 참가자가 모두 READY일 때 방장의 START 버튼 활성화
- 방장이 START를 누르면 방장도 자동 READY 처리 후 1분간 총 선택 시간 제공
- 이 시간에는 팀·맵 변경 및 준비 해제를 잠그고 총 선택만 허용
- 1분이 끝나면 선택한 총으로 자동 시작하며, 참가자 퇴장 등으로 시작 조건이 깨지면 취소
- 방장만 멀티플레이 맵을 선택하고 경기를 시작할 수 있음
- 같은 컴퓨터의 브라우저 탭 또는 창이 `BroadcastChannel`을 통해 연결됨
- 현재 버전은 인터넷 서버 방식이 아니므로 서로 다른 컴퓨터 간 온라인 연결은 지원하지 않음

### 봇전

- 멀티플레이와 동일한 6개 매치 맵 중 하나를 선택 가능
- 맵 선택 시 실제 벽 구조와 BLUE/RED 스폰 위치 미리보기 제공
- 플레이어와 아군 봇 4명 대 적군 봇 5명으로 5대5 경기
- 아군과 적군 봇이 이동하고 서로 다른 목표를 공격함
- 플레이어와 봇이 사망하면 상대 팀 점수 증가

### 훈련장

- 매치 맵과 분리된 전용 `COMBAT TRAINING RANGE`
- 반응형 과녁 8개 배치
- 과녁 명중과 빗나감 횟수를 별도로 표시
- 명중한 과녁은 잠시 내려간 뒤 다시 등장
- 시간 제한 없이 훈련 가능
- 훈련 중 ESC를 누르면 로비로 복귀

## 경기 규칙

- 제한 시간: 25분
- 승리 조건: 먼저 100점을 획득한 팀
- 시간이 끝나면 점수가 높은 팀 승리
- 시간 종료 시 동점이면 무승부
- 경기 종료 결과와 최종 점수를 크게 표시
- 결과 화면 표시 3초 후 대기방으로 복귀
- 매치 로딩부터 결과 화면 종료까지 게임 내부의 대기방 나가기 차단
- 경기 중 F5 / Ctrl+R 새로고침 차단 및 브라우저 이탈 시 확인 요청
- 경기 시작 시 전체화면 전환, 브라우저가 자동 전환을 제한하면 화면 상단 버튼 클릭
- 운영체제 창 닫기·Alt+F4는 가능하며 훈련장은 기존 ESC 나가기 유지

### 멀티플레이 퍼즈

1. Enter를 눌러 채팅창을 엽니다.
2. `/paused`를 입력합니다.
3. 모든 참가자의 이동, 사격, 봇, 경기 시간과 장전 진행이 정지됩니다.
4. 퍼즈를 실행한 플레이어만 `RESUME` 버튼으로 경기를 재개할 수 있습니다.

### 항복 투표

- 멀티플레이 경기 중 ESC를 누르면 항복 투표 화면 표시
- 경기 진행 시간 5분 후 항복 버튼 활성화
- 퍼즈 상태로 보낸 시간은 5분 조건에 포함되지 않음
- 해당 팀 인원의 과반수가 찬성하면 항복 처리
- 항복한 팀의 상대 팀이 승리
- 같은 플레이어의 중복 투표 방지

## 전장

매치 맵은 원본 구조의 가로와 세로를 각각 5배 확장하여 전체 플레이 면적이 25배입니다. BLUE 팀은 하부 중앙, RED 팀은 북부 중앙에서 생성됩니다.

- `SECTOR 9` — 중앙 반응로
- `DUST OUTPOST` — 개방형 교차로
- `NEON HARBOR` — 컨테이너 통로
- `IRON CITADEL` — 요새화된 중앙 구역
- `SUBZERO LAB` — 좁은 연구소 회랑
- `SKYLINE 21` — 고층 도시 구역

맵마다 콘크리트 회색, 모래색, 적갈색, 빙설색 등 서로 다른 벽 팔레트를 사용합니다. 미니맵에는 플레이어와 아군만 표시되며 적군은 표시되지 않습니다.

## 무기

- `K2` — 균형형 소총
- `AK-47` — 높은 피해량과 강한 반동
- `M16` — 빠른 연사와 높은 제어력

모든 무기의 장전 시간은 5초입니다. 장전 중에는 이동속도가 0.5배가 되며 다음 동작이 표시됩니다.

1. 총을 옆으로 돌려 전체 총기 표시
2. 빈 탄창 분리
3. 전술 배낭에 빈 탄창 수납
4. 새 탄창에 탄약 삽입
5. 탄창 재장착
6. 총구를 원래 방향으로 복귀

## 조작법

| 입력 | 기능 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 상하좌우 조준 |
| 마우스 왼쪽 | 사격 |
| 마우스 오른쪽 | 줌 전환 |
| 줌 상태에서 휠 | 1.5배~2.0배, 0.1배 단위 조절 |
| 줌 해제 상태에서 휠 | 연사/단발 모드 전환 |
| R | 장전 |
| 1 / 2 / 3 | K2 / AK-47 / M16 선택 |
| Tab 누르고 있기 | 킬·어시스트·데스 점수판 표시 |
| Enter | 멀티플레이 채팅 열기 |
| ESC | 멀티플레이 항복 투표 / 훈련장 나가기 |

사망하면 줌이 자동 해제되고 팀 스폰 지역에서 다시 생성됩니다. 발소리, 총성, 총구 화염과 탄피 배출 애니메이션을 지원합니다.

## 닉네임

- 최대 12자까지 입력 가능
- 로비 이동과 페이지 갱신 후에도 현재 게임 세션 동안 유지
- 새 닉네임을 입력하면 즉시 갱신
- 게임 창을 완전히 종료하면 세션 초기화

## EXE 다시 빌드하기

PowerShell에서 다음 명령을 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File packaging/build-exe.ps1
```

빌드 과정에서 다음 항목이 자동으로 처리됩니다.

- HTML, CSS, JavaScript를 EXE 리소스로 포함
- 16px부터 256px까지의 다중 해상도 소총 ICO 생성
- EXE 및 작업표시줄 아이콘 연결
- Windows GUI 실행 파일 `NeonStrike.exe` 생성

## 주요 파일

```text
dist/index.html                    게임 화면과 메뉴
dist/styles.css                   UI 스타일
dist/game.js                      게임 로직
packaging/NeonStrikeLauncher.cs   Windows 런처
packaging/build-exe.ps1           EXE 빌드 스크립트
packaging/create-icon.ps1         ICO 생성 스크립트
packaging/neon-strike-icon.svg    소총 아이콘 원본
NeonStrike.exe                    완성된 Windows 실행 파일
```
