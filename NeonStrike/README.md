## 빠른 실행

Windows에서는 루트 폴더의 `NeonStrike.exe`를 실행하세요.

- Microsoft Edge 전용 저장 프로필의 앱 창으로 실행하고 전체화면 전환
- 닉네임을 유지하기 위해 `%LOCALAPPDATA%\NeonStrikeGame\BrowserProfile` 사용
- EXE와 작업표시줄에 소총 실루엣 아이콘 표시
- 별도 설치 과정과 외부 게임 서버 불필요
- Microsoft Edge가 설치되어 있어야 함

EXE와 브라우저를 함께 사용하려면 먼저 `NeonStrike.exe`를 실행하여 공통 서버를 시작하세요. 이후 브라우저에서 `http://127.0.0.1:8765/`에 접속합니다. `dist/index.html`을 직접 열어도 이 주소로 연결됩니다. 서버가 꺼져 있으면 EXE 실행 안내가 표시됩니다.

서버는 EXE 실행 시 자동으로 시작하며, 이미 실행 중이면 같은 서버를 사용합니다. 별도의 Python / Node 설치가 필요하지 않습니다. 서버 없이 임의 정적 서버에서 실행하는 방식은 지원하지 않습니다.

## 게임 모드

### 방 만들기

`방 만들기`를 누르면 다음 두 종류 중 하나를 선택할 수 있습니다.

- `PLAYER TEAM VS PLAYER TEAM` — 사람 팀 대 사람 팀, 최대 5대5
- `PLAYER TEAM VS BOT TEAM` — BLUE 사람 최대 5명 대 RED 봇 동일 인원

방 코드 및 방 목록으로 참가하며, 대기방과 방 목록에 경기 종류를 표시합니다.

### 멀티플레이

- 방 만들기, 빠른 시작, 방 코드 참가 및 방 목록 지원
- 방장이 대기방에서 나가면 남은 참가자 중 가장 먼저 입장한 사람에게 방장 승계
- 팀을 변경해도 방장 승계에 사용하는 입장 순서는 유지
- 마지막 참가자가 나가면 대기방 자동 삭제
- 메인 로비의 방 목록은 1초마다 서버 상태를 확인하며, 다른 PC의 방 생성·삭제와 방장 변경도 자동 반영
- 접속 플레이어 목록은 1초마다 갱신하며, 게임을 정상 종료한 플레이어는 다른 PC 목록에서도 제거
- 새 버전 적용 시 서버를 새 실행 파일로 다시 실행하고, 다른 PC의 게임 페이지도 새로고침
- 메인 로비와 일반 대기방의 총 선택 제거
- 방장 START 후 1분 동안 전용 총 선택 화면에서 K2 / AK-47 / M16 선택
- 총 선택 버튼에 K2 / AK-47 / M16의 측면 디자인 표시
- 캐릭터 선택창 스타일의 전용 화면에 큰 총 디자인, 무기 특성, 피해량·연사속도·탄창 표시
- 아군 선택 현황과 남은 시간을 표시하고, 시간 종료 시 선택한 총 자동 적용
- 대기방에서 선택한 총은 참가자 명단, 로딩 화면과 실제 경기에 반영
- 경기 전 총 변경은 START 후 선택 시간에만 가능하며 준비 상태 유지
- 상대 팀의 총 정보는 대기방, 로딩 화면과 점수판에서 숨김
- 팀 선택은 방 입장 후 대기방에서 진행
- 대기방의 `BLUE TEAM` / `RED TEAM` 버튼으로 팀 변경 가능하며 다른 참가자에게 즉시 반영
- 팀 변경 시 준비 상태가 해제되고 진행 중인 시작 카운트다운 취소
- BLUE 5명 / RED 5명, 방당 최대 10명 참가 가능
- 신규 방은 입장 순서대로 BLUE → RED → BLUE → RED 교대 배정
- 퇴장이나 팀 변경으로 인원 차이가 생기면 인원이 적은 팀부터 배정
- 팀 변경 후 인원 차이는 최대 1명이며, 경기 재시작 시 선택한 팀 유지
- 5명이 찬 팀으로 변경할 수 없으며, 10명이 찬 방은 추가 참가 불가
- BLUE / RED 인원이 같아야 준비 및 경기 시작 가능 (1대1부터 5대5까지)
- 전원 준비 후에도 팀 인원이 달라지면 시작 카운트다운 취소
- 대기방 플레이어 목록을 BLUE TEAM / RED TEAM 영역으로 분리하고 팀별 인원수 표시
- BLUE는 파란색, RED는 빨간색 테두리·배경·팀 라벨로 구분
- 내 팀에는 `MY TEAM`, 내 플레이어에는 `(YOU)`와 강조 테두리 표시
- 팀에 참가자가 없으면 빈 팀 안내 표시
- 방장에게는 `START` 버튼만 표시되며, 나머지 참가자는 `READY` / `NOT READY`만 사용 가능
- 두 팀 인원이 같고 방장을 제외한 참가자가 모두 READY일 때 방장의 START 버튼 활성화
- 방장이 START를 누르면 방장도 자동 READY 처리 후 1분간 총 선택 시간 제공
- 이 시간에는 팀·맵 변경 및 준비 해제를 잠그고 총 선택만 허용
- 1분이 끝나면 선택한 총으로 자동 시작하며, 참가자 퇴장 등으로 시작 조건이 깨지면 취소
- 방장만 멀티플레이 맵을 선택하고 경기를 시작할 수 있음
- EXE와 일반 브라우저가 공통 HTTP 서버로 방·접속 목록·초대·경기 상태 공유
- 공통 주소: `http://127.0.0.1:8765/` 또는 서버 컴퓨터의 IP 주소
- 다른 플레이어와 봇을 면 기반 3D 병사 모델로 표시 (벽 뒤 플레이어는 숨김)
- 머리·헬멧·몸통·팔·다리·배낭·총을 입체로 구성하고 방향에 따라 앞·옆·뒷모습 변화
- 거리별 원근감, 면별 음영과 걷기 동작 적용
- 채팅·정지·마우스 해제 중에도 주기적으로 상태를 전송하여 플레이어 표시 유지
- 다른 컴퓨터에서도 같은 서버 주소에 접속하면 멀티플레이 가능

### 연습용 P1+B4 VS B5

메인 로비의 `연습용 P1+B4 VS B5` 버튼으로 참가자 초대 없이 혼자 연습합니다. 플레이어 1명 + 아군 봇 4명 대 적군 봇 5명으로 진행합니다.

- 멀티플레이와 같은 대기방에서 팀·맵 확인 후 START로 시작
- 봇 9명은 자동 READY, 플레이어가 START를 누르면 1분 총 선택 화면 진행
- 팀 변경 시 봇 팀 구성을 자동 조정하여 5대5 유지
- ESC 항복 메뉴에서 즉시 항복 가능: 5분 제한·투표 없이 즉시 종료
- 항복한 팀의 점수는 `항복`으로 표시하고 결과 후 봇전 대기방 복귀

- 멀티플레이와 동일한 6개 매치 맵 중 하나를 선택 가능
- 맵 선택 시 실제 벽 구조와 BLUE/RED 스폰 위치 미리보기 제공
- 플레이어와 아군 봇 4명 대 적군 봇 5명으로 5대5 경기
- 아군과 적군 봇이 이동하고 서로 다른 목표를 공격함
- 플레이어와 봇이 사망하면 상대 팀 점수 증가

### PLAYER TEAM VS BOT 협동전

- `방 만들기` → `PLAYER TEAM VS BOT TEAM`을 선택하여 협동전 대기방 생성
- 방 코드 또는 방 목록을 통해 같은 서버에 접속한 다른 컴퓨터·탭·창에서 참가
- BLUE는 사람 플레이어만 최대 5명, RED는 적군 봇만 구성
- 사람 인원에 맞춰 적군 봇 자동 조정: 1명→봇 1명, 2명→봇 2명, …, 5명→봇 5명
- 아군 보충 봇은 없으며 팀 변경 불가
- 대기방에서 사람 참가·퇴장 시 RED 봇 인원 즉시 조정
- 봇은 자동 READY, 사람 참가자는 READY, 방장은 START 후 1분 총 선택
- 방장이 봇 이동·피해·점수를 관리하고 모든 참가자에게 동기화
- 진행 중인 협동전은 추가 참가 차단, 경기 종료 후 같은 대기방에서 재시작
- 항복 투표 인원은 사람 참가자만 계산하며 기존 팀 투표 규칙 적용

### 훈련장

- 매치 맵과 분리된 전용 `COMBAT TRAINING RANGE`
- 반응형 과녁 8개 배치
- 과녁 명중과 빗나감 횟수를 별도로 표시
- 명중한 과녁은 잠시 내려간 뒤 다시 등장
- 시간 제한 없이 훈련 가능
- 훈련 중 ESC를 누르면 전용 마우스 포인터와 메뉴 표시
- 메뉴의 RESUME으로 훈련 재개, 훈련장 나가기 버튼으로 로비 복귀

## 경기 규칙

- 제한 시간: 25분
- 승리 조건: 먼저 100점을 획득한 팀
- 시간이 끝나면 점수가 높은 팀 승리
- 시간 종료 시 동점이면 무승부
- 경기 종료 결과와 최종 점수를 크게 표시
- 결과 화면 표시 3초 후 대기방으로 복귀
- 매치 로딩부터 결과 화면 종료까지 게임 내부의 대기방 나가기 차단
- 경기 중 F5 / Ctrl+R 새로고침 차단 및 브라우저 이탈 시 확인 요청
- 경기 시작 시 전체화면 전환, 브라우저가 자동 전환을 제한하면 화면 상단 버튼 클릭
- 운영체제 창 닫기·Alt+F4는 가능하며 훈련장은 ESC 메뉴의 나가기 버튼으로 복귀

### 멀티플레이 퍼즈

1. Enter를 눌러 채팅창을 엽니다.
2. `/paused`를 입력합니다.
3. 모든 참가자의 이동, 사격, 봇, 경기 시간과 장전 진행이 정지됩니다.
4. 퍼즈를 실행한 플레이어만 `RESUME` 버튼으로 경기를 재개할 수 있습니다.

### 항복 투표

`PLAYER TEAM VS PLAYER TEAM`과 `PLAYER TEAM VS BOT TEAM` 멀티플레이는 같은 항복 투표 UI와 규칙을 사용합니다. 투표 대상과 과반 기준은 해당 팀의 사람 플레이어만 포함합니다. 혼자 하는 `P1+B4 VS B5` 연습전은 투표 없이 즉시 항복합니다.

- 경기 진행 5분 후 ESC 메뉴에서 팀 항복 투표 시작 가능 (퍼즈 시간 제외)
- 시작자는 즉시 자동 찬성 처리하고, 같은 팀원에게 항복 투표창 자동 표시
- 자동 투표창에서 남은 시간 확인 및 찬성·반대 버튼 클릭 가능
- 투표창을 닫아도 우측 팀 투표 현황은 유지되며 채팅 명령으로 참여 가능
- 상대 팀에는 투표창·투표 현황을 표시하지 않음
- BLUE / RED 팀이 각자 독립적으로 항복 투표를 동시 진행할 수 있음
- 각 팀은 자기 팀 투표에만 참여 가능하며 상대 팀 투표 현황은 숨김
- Enter로 채팅을 열고 `/sp` 입력 시 찬성, `/nsp` 입력 시 반대
- 우측에 투표 시작 당시 실제 팀 인원수만큼 사각형 표시: 찬성 초록색, 반대 빨간색, 미투표 회색
- 투표 진행 중 우측 찬성·반대 버튼 항상 표시
- ESC / V로 투표창을 열거나 Enter로 채팅을 열면 마우스 잠금 해제 후 클릭 투표 가능
- 투표창의 항복 시작·찬성·반대 버튼도 마우스로 클릭 가능
- 버튼 클릭과 `/sp` / `/nsp` 채팅 명령은 동일하게 집계하며 이미 투표한 플레이어의 버튼 비활성화
- 중복 투표 및 투표 변경 불가
- 투표 시작 당시 팀 전체 인원(기권·미투표자 포함)의 과반 찬성이 필요
- 예: 5명 팀은 3명 찬성 필요. 반대나 기권은 찬성으로 계산하지 않음
- 진행 중 과반 찬성 달성 시 즉시 항복 처리하고 상대 팀 승리
- 항복한 팀의 점수는 HUD·점수판·결과 화면에서 `항복`으로 대체 (예: `항복 : 20`, `20 : 항복`)
- 동시 투표 시 먼저 가결된 팀의 항복으로 경기 종료, 다음 경기에는 숫자 점수로 초기화
- 15초 종료 시 과반 찬성 미달이면 투표만 종료하고 경기 계속
- 반대 과반 또는 시간 종료로 부결되면 해당 팀은 3분간 재투표 불가
- 남은 시간을 버튼·안내문에 표시하고 3분 후 자동 재활성화, 상대 팀 투표에는 영향 없음
- 반대가 팀 전체 인원의 과반에 도달하면 15초를 기다리지 않고 투표 즉시 부결, 경기 계속
- 찬성·반대 과반 기준: 5명→3명, 4명→3명, 3명→2명, 2명→2명, 1명→1명
- 1명 팀은 시작자의 자동 찬성으로 항복 투표 시작 즉시 항복
- 반대·기권이 과반이면 경기가 종료되지 않음

## 공통 서버

- 기본 주소는 `http://127.0.0.1:8765/`, EXE 실행 시 백그라운드로 시작
- 서버는 게임 창을 닫아도 계속 실행되며 컴퓨터 재시작 시 종료
- 방·접속 데이터는 서버 메모리에 보관되므로 서버 재시작 시 초기화
- 서버는 IPv4 네트워크 연결을 허용하며 다른 컴퓨터에서도 접속 가능
- 8765 포트를 다른 프로그램이 사용하면 EXE에 서버 시작 오류 표시

## 다른 컴퓨터와 플레이하기

1. 서버 역할을 할 컴퓨터에서 새 버전의 `NeonStrike.exe`를 실행합니다.
2. 로비의 **친구에게 공유할 주소**를 확인합니다. 예: `http://192.168.0.10:8765/`.
3. 다른 컴퓨터에서는 브라우저로 그 주소에 접속하거나, EXE 로비의 **다른 컴퓨터 서버 접속** 버튼에 주소를 입력합니다.
4. 같은 서버에서 방을 만들고 방 목록·코드·초대로 참가합니다. PVP와 협동전 모두 지원합니다. 각자 `127.0.0.1`에 접속하면 서로 다른 서버이므로 함께 플레이할 수 없습니다.

같은 공유기 또는 LAN에서 사용하는 경우 Windows 방화벽의 개인 네트워크에서 TCP 8765 수신을 허용해야 합니다. 제공된 `packaging/allow-network.ps1`를 관리자 PowerShell로 실행하면 같은 서브넷의 접속만 허용하는 규칙을 추가합니다. 서버 컴퓨터는 경기 종료까지 켜두세요. 이전 버전 서버가 실행 중이라면 컴퓨터를 재시작한 후 새 EXE를 실행하세요.

서로 다른 인터넷 회선에서는 서버 컴퓨터 공유기에 TCP 8765 포트 전달을 설정하고 공인 IP 주소로 접속해야 합니다. 이 경우 방화벽 수신 범위도 상대 IP에 맞게 설정해야 합니다. 이중 공유기·CGNAT 환경에서는 직접 접속이 제한될 수 있으므로 같은 VPN 네트워크 주소를 사용할 수 있습니다. 자동 중계 서버·자동 포트 전달은 포함하지 않습니다. 현재 서버는 로그인이나 TLS 암호화를 제공하지 않으므로 신뢰하는 사람과의 LAN/VPN 플레이를 권장합니다.

### 서버 링크 공유

로비의 **서버 링크 복사 · Ctrl+C** 버튼을 누르면 친구에게 보낼 주소가 복사됩니다. 로비에서 입력 중이 아니고 선택된 글자가 없을 때 Ctrl+C로도 서버 링크를 복사할 수 있습니다. 주소 입력칸을 클릭하면 전체 주소가 선택되어 기본 Ctrl+C 복사를 사용할 수 있습니다. 서버 컴퓨터의 localhost 접속에서는 LAN 주소를, 다른 컴퓨터에서 접속한 경우 현재 서버 주소를 공유합니다.


## PC EXE와 APK 연동

PC 실행 파일은 `NeonStrike.exe` 하나로 통합합니다. 이 파일에 PC 게임 화면, 공통 HTTP 서버, APK용 터치 조작이 함께 포함되어 있으므로 별도 `NeonStrike-mobile*.exe`는 필요하지 않습니다.

1. PC에서 `NeonStrike.exe`를 실행합니다.
2. PC 로비의 **서버 링크 복사 · Ctrl+C**로 접속 주소를 확인합니다.
3. 휴대폰에서 `android/NeonStrike-1.1.1-debug.apk`를 설치하고 접속창에 서버의 IPv4 주소만 입력합니다(예: `192.168.0.10`). 앱이 `http://입력한IP:8765/`로 접속하며 포트는 8765로 고정됩니다.
4. PC 또는 APK에서 방을 만든 뒤 다른 기기에서 같은 방 코드나 방 목록으로 참가합니다. 접속 목록·초대·방장·무기 선택·경기 상태는 같은 서버를 사용합니다.

PC와 휴대폰이 같은 Wi-Fi에 있으면 PC의 LAN 주소를 사용합니다. 모바일 데이터나 다른 집에서는 외부에서 접속 가능한 공인 IP 주소가 필요합니다. 휴대폰의 `127.0.0.1`은 휴대폰 자신이므로 PC 서버에 연결되지 않습니다. 서버 PC는 플레이 중 켜두어야 합니다.

- 개인이 나가도 진행 중인 경기는 계속됩니다. 방장이 나가면 남은 참가자에게 방장을 넘깁니다.

- 한 팀 전원이 30초 이상 연결되지 않으면 해당 팀은 전원 탈주패배합니다. 양 팀 전원이 이탈하면 무승부로 종료합니다. 30초는 팀 전원 탈주 판정 시간이며 개인 복귀 제한 시간이 아닙니다.

- 서버가 1초마다 접속 상태, 총 선택 종료 시점과 경기 제한 시간을 확인합니다. 화면이 숨겨져도 경기 시간과 탈주 판정은 PC 서버에서 진행됩니다.
- APK는 알림이 표시되는 연결 유지 서비스를 사용합니다. 다른 앱으로 전환하는 것만으로 탈주 처리하지 않습니다. 최근 앱 목록에서 제거하거나 강제 종료하면 서비스도 종료됩니다.
- Android 15의 데이터 동기화 서비스는 백그라운드에서 24시간당 총 6시간 제한이 있습니다. OS 강제 종료와 네트워크 단절 시 연결이 중단될 수 있습니다.

### APK 화면 끊김 개선

경기 중 방·온라인 플레이어 목록 조회와 저장은 비동기 통신 및 스냅샷 캐시를 사용합니다. 서버 응답을 기다리면서 화면 렌더링을 멈추는 동기 통신을 줄였으며, 목록 갱신은 1초마다 유지합니다.

모바일 게임 캔버스의 고밀도 픽셀 렌더링 부담과 광선 계산 중 반복 삼각함수 호출도 줄였습니다. 같은 경기에서 연결 유지 서비스를 반복 시작하지 않으며, APK가 화면에 있을 때 서비스의 중복 접속 확인 요청을 보내지 않습니다.

### 항복 가결 시 경기 종료 처리 보완

항복 가결 상태를 받은 클라이언트가 별도 matchend 메시지를 기다리지 않고 즉시 경기를 멈추고 결과 화면을 표시합니다. 방장도 가결 시 경기 종료를 먼저 실행한 뒤 투표 결과를 전송합니다. 서버는 방장이 전송한 가결 투표의 팀원·중복 여부·과반 찬성을 확인해 경기 종료 상태를 기록하고 양 팀에 종료 사건을 보냅니다. 종료 메시지가 누락되어도 서버 조회에서 종료를 확인할 수 있습니다. 결과 화면에서는 항복 팀 점수가 항복으로 표시되며 3초 후 대기방으로 복귀합니다.

검증: 방장 과반 가결과 별도 종료 메시지를 받지 못한 참가자 모두 경기 정지 → 항복 점수 표시 → 대기방 복귀하는 테스트를 통과했습니다. 실제 HTTP 서버에서 별도 클라이언트 matchend 없이 가결 투표만으로 종료 상태·승리 팀·항복 팀과 서버 종료 사건을 확인했고, 과반 미달과 방장이 아닌 전송은 종료로 처리되지 않는 것도 확인했습니다. 기존 복귀·총 선택 테스트도 통과했습니다. 휴대폰 실기기 검증은 별도로 필요합니다.


### 연결 끊김 관련 요청 부하 개선

게임과 무관한 접속자·초대 채널의 조회 간격을 150ms에서 1초로 조절해 반복 요청을 줄였습니다. 경기 채널의 150ms 조회와 접속자 목록의 1초 갱신은 유지합니다. 서버는 TCP 지연 전송을 끄고 HTTP 응답 헤더와 본문을 한 번에 전송하며, 최소 작업 스레드를 최대 32개까지 확보해 동시 요청 시 초기 대기를 줄입니다. 기존 조회 제한 시간·재시도·연결 복구 안내도 유지합니다.

검증: 로컬 모의 클라이언트 10개가 접속 상태·공유 정보·세션·채널 전송 및 조회를 포함한 HTTP 요청 500건을 보내고 모든 요청이 성공했습니다. 해당 단기 시험의 왕복 시간 중앙값은 3.0ms, 95백분위는 9.3ms였습니다. 실제 외부 인터넷이나 휴대폰에서의 핑·장시간 연결 안정성을 나타내는 수치는 아닙니다. 항복 종료와 통신 복구·전송 큐 회귀 테스트도 확인했습니다. 새 EXE로 서버를 실행하면 같은 서버에 접속하는 APK에도 적용됩니다.


### 동일 플레이어 중복 등록 방지

같은 앱·브라우저 저장 프로필의 플레이어 ID를 유지하며, 대기방 재접속 시 기존 ID가 이미 등록되어 있으면 팀을 유지한 채 이름을 갱신합니다. 방이 가득 차 있어도 기존 등록을 중복 추가하지 않습니다. 서버도 방 명단을 저장할 때 같은 ID를 한 번만 남기고 인원수를 다시 계산해 경기 명단에 중복이 전달되지 않도록 합니다. 닉네임이 같아도 ID가 다른 플레이어는 별도 인원입니다.

검증: 10인 방에 기존 ID로 재접속하여 중복 없이 기존 팀을 유지하는 클라이언트 테스트와, 실제 서버에 중복 ID 명단을 반복 저장하여 방 인원·총 선택 경기 명단이 중복되지 않는 테스트를 통과했습니다. 항복 종료 서버 테스트도 통과했습니다. PC EXE와 같은 서버에 접속하는 APK에 공통 적용됩니다.

검증: 실제 서버에서 퇴장 후 지연된 접속 유지·이전 재입장 요청에도 플레이어가 복원되지 않고 방장이 이전되는 것을 확인했습니다. 중복 방 명단 테스트와 모바일 확대·축소 범위·채팅 중 조작 차단 테스트를 통과했습니다. 휴대폰 실기기 터치 확인은 별도로 필요합니다.

검증: 실제 HTTP 서버에 퇴장 후 오래된 방 명단·접속자 저장·채널 메시지·세션 요청을 반복해 역순 전송해도 플레이어가 다시 등록되지 않는 것을 확인했습니다. 명시적 재입장, 재입장 이후 도착한 이전 퇴장 요청, 네트워크 오류 후 퇴장 재시도, 항복 종료·모바일 사격 모드·동시 요청 500건도 테스트했습니다. 테스트 서버는 종료했습니다. 실제 휴대폰의 Wi-Fi·셀룰러 전환을 직접 측정한 것은 아니며, 모든 네트워크가 끊겨 퇴장 요청이 전달되지 않으면 기존 연결 만료 처리가 적용됩니다.

검증: 실제 서버의 퇴장 응답 직후 인원·방장·빈 방 삭제가 이미 반영되고 사건에 최신 명단이 포함되는 것을 확인했습니다. 캐시 즉시 갱신·접속자 제거와 네트워크 전환 시 오래된 요청 차단, 항복 종료 테스트도 통과했습니다. 서버는 종료 상태로 유지합니다.


### 데이터 → Wi-Fi 전환 후 로비 접속자 재표시 보완

방에 참가하지 않은 로비 사용자도 별도의 접속자 퇴장 시각을 기록합니다. 퇴장 이후 늦게 도착한 이전 접속자 저장 요청과 알림을 차단하고, 퇴장 알림을 받기 전에 시작된 목록 조회가 나중에 도착해도 삭제된 플레이어를 캐시에 복원하지 않습니다. 닫힌 채널에 남은 일반 메시지는 보내지 않으며 퇴장 알림만 마무리합니다. 새로 앱을 열어 생성한 최신 접속 정보는 정상적으로 표시합니다.

검증: 방 세션이 없는 사용자도 퇴장 후 오래된 저장·접속 알림이 반복 도착해도 로비 접속자 목록에 복원되지 않는 서버 테스트와, 오래된 목록 조회 응답의 역순 도착 테스트를 통과했습니다. 방 퇴장·재입장·즉시 명단 반영 테스트도 통과했습니다. 실제 휴대폰의 데이터↔Wi-Fi 전환은 별도 실기기 확인이 필요합니다. 서버는 종료 상태입니다.


### 모바일 TAB 점수표 버튼 — Android 빌드 16

전투 중 ESC 옆 TAB 버튼을 누르면 PC TAB과 같은 양 팀 점수·킬·도움·사망 점수표를 표시하고 다시 누르면 닫습니다. 열려 있는 점수표는 0.5초마다 갱신합니다. 경기 종료 시 자동으로 닫으며 로비·총 선택에서는 버튼을 표시하지 않습니다. 점수표 열기·닫기, 발사 중지, 메뉴·채팅·정지 상태의 조작 차단과 항복 후 복귀 테스트를 확인했습니다. APK 1.0.6 빌드 16과 EXE·통합 ZIP에 반영했습니다.


### APK 서버 주소 직접 입력 — Android 빌드 17

앱 접속창은 이전 주소나 지정된 공인 IP를 자동으로 채우지 않고 매번 `http://`만 표시합니다. 뒤에 실행 중인 PC 서버 IP와 포트를 입력하고 접속을 누르세요(예: `http://192.168.0.10:8765/`). HTTP 주소에서 포트를 생략하면 8765를 사용합니다. 주소 없이 접속하면 입력 오류를 표시합니다. 모바일에서는 PC 서버 주소를 사용해야 하며, 서버가 실행 중이어야 접속할 수 있습니다. APK 1.0.6 빌드 17을 재빌드하고 서명·정렬·통합 ZIP을 확인했습니다.


### APK IP 입력 / 포트 8765 고정 — 빌드 18

최신 APK 접속창에는 서버의 IPv4 주소만 직접 입력합니다(예: `192.168.0.10`). 앱이 `http://입력한IP:8765/`로 접속하므로 프로토콜이나 포트를 입력할 필요가 없습니다. 포트는 8765로 고정됩니다. 잘못된 IPv4, 휴대폰 자신을 가리키는 127.x 주소, 0.0.0.0 등은 입력 오류로 안내합니다. 기존 빌드 17의 주소 입력 방식은 빌드 18에서 대체되었습니다. APK 빌드·서명·정렬과 통합 ZIP 무결성을 확인했습니다.


## 1.1.0 — 상대 플레이어 개머리판 공격 모션 / Android 빌드 19

PC의 F 키와 모바일 개머리판 버튼으로 공격하면 다른 플레이어 화면에서도 양팔과 소총 전체가 움직이며 개머리판을 휘두르는 모션을 표시합니다. 빗나간 공격도 모션을 전송합니다. 공격 알림을 일반 위치 갱신과 별도로 보내고, 수신 기기의 시각으로 420ms 모션을 재생하여 기기 간 시계 차이나 위치 갱신 제한 때문에 모션이 누락되는 문제를 개선했습니다. 중복 공격 알림은 다시 재생하지 않으며, 일반 상태 갱신으로 받은 새 공격 정보도 모션에 반영합니다. 피해량 50, 공격 거리 및 재사용 대기시간은 유지됩니다.

공통 게임 코드를 새 Windows EXE에 포함했고, APK 1.1.0(버전 코드 19)과 PC·APK 통합 ZIP을 제공합니다. 기존 서버를 종료하고 새 EXE로 실행한 뒤 각 PC 페이지를 새로고침하고 휴대폰에는 새 APK를 설치하세요. 기존 APK와 같은 서명 키를 사용합니다. 접속창에는 서버 IPv4 주소만 입력하며 포트는 8765로 고정됩니다.

검증: 수신 기기 시각 기준 모션, 중복 재생 방지, 상태 갱신의 공격 정보 반영, 팔·소총 전체의 자세 변화 및 모션 종료를 자동 테스트했습니다. EXE 컴파일과 APK 서명·정렬, 통합 ZIP의 파일 무결성도 확인했습니다. 실제 휴대폰과 PC를 함께 사용한 화면 확인은 별도로 필요합니다. 업데이트 작업 후 서버는 종료 상태로 둡니다.

## 1.1.1 — 상대 총성·총구 섬광·탄피 / Android 빌드 20

상대 플레이어가 발사하면 명중 여부와 관계없이 발사 위치·방향을 전송합니다. 내 시선을 기준으로 좌우 스테레오 총성을 재생하고, 멀리 있는 총성은 작게, 벽 뒤 총성은 더 작게 들립니다. 총성의 저음도 같은 방향으로 출력합니다. 방향 구분에는 이어폰 또는 스테레오 스피커를 사용하세요.

상대 소총의 총구 위치에 짧은 섬광을 표시하고, 배출구에서 탄피가 튀어나와 중력에 따라 떨어지고 한 번 튕기도록 적용했습니다. 벽 뒤 탄피는 표시하지 않으며, 최대 48개·2.5초 수명으로 제한합니다. 중복 발사 알림은 효과를 다시 재생하지 않습니다. 기존 상대 장전·개머리판 모션을 포함합니다.

검증: 방향별 좌우 소리·거리 감쇠·벽 감쇠, 발사 이벤트 중복 차단, 섬광 상태 유지, 탄피 중력·반동·수명·개수 제한 및 기존 장전·개머리판 모션을 자동 테스트했습니다. EXE 컴파일, APK 서명·정렬과 통합 ZIP 무결성도 검사했습니다. 실제 휴대폰 화면과 이어폰 음향 확인은 별도로 필요합니다. 서버는 종료 상태로 둡니다.

빌드 시 서명 비밀번호는 로컬 환경 변수 `NEONSTRIKE_KEYSTORE_PASSWORD`와 `NEONSTRIKE_KEY_PASSWORD`로 제공하세요. 기존 앱 위에 설치하려면 기존 키와 동일한 비밀번호를 사용해야 합니다. 비밀번호와 keystore 파일은 저장소·배포 ZIP에 포함하지 않습니다.
