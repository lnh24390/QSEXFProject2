# NEON STRIKE

## Windows EXE

`NeonStrike.exe`를 실행하면 별도의 서버 없이 게임이 Microsoft Edge 앱 창으로 열립니다. EXE를 다시 만들려면 `powershell -ExecutionPolicy Bypass -File packaging/build-exe.ps1`을 실행하세요.

브라우저에서 실행되는 레이캐스팅 기반 멀티플레이 FPS입니다.

## 실행

`dist/index.html`을 브라우저에서 열거나 정적 서버를 사용하세요.

```powershell
python -m http.server 8080 --directory dist
```

그 후 `http://localhost:8080`에 접속합니다. 멀티플레이 테스트는 같은 브라우저에서 두 개의 탭을 열고 같은 룸 코드를 입력하면 됩니다. 서로 다른 팀을 선택해야 공격할 수 있습니다.

## 맵: SECTOR 9

21x21 규모의 대칭형 팀 데스매치 전장입니다. 양 끝에 BLUE/RED 스폰이 있고 중앙 발전소, 북부 터널, 남부 회랑이 연결됩니다. 중앙은 빠른 교전, 외곽 통로는 우회 공격에 유리합니다. HUD 왼쪽 위 미니맵에서 플레이어 위치를 확인할 수 있습니다.

야간 네온 하늘에는 별, 초승달, 도시 실루엣이 표시됩니다. 전장에는 충돌 판정이 적용되는 중앙 반응로, 에너지 기둥, 보급 상자, 통신 비콘이 배치되어 엄폐와 우회 플레이에 활용할 수 있습니다.

팀 스폰은 BLUE가 맵 하부 중앙, RED가 맵 북부 중앙에 배치됩니다. 사망한 플레이어와 봇은 각자의 팀 스폰 구역에서 다시 생성됩니다.

## 조작

- WASD: 이동
- 마우스: 조준
- 클릭: 사격
- R: 재장전
- ESC: 일시 정지
- 1: K2 소총 (균형형)
- 2: AK-47 (고화력, 강한 반동)
- 3: M16 (빠른 연사, 높은 명중률)
