# NEON DRIFT 2.0 테스트 결과

현재 플레이어 이미지: `전투기.png`의 배경을 내장 image_gen으로 제거한 `전투기-배경제거.png`. 원본은 보관하고 `index.html`의 `player-sprite`를 새 파일로 연결했습니다. PNG의 알파 채널과 투명 배경을 확인했습니다. 아래 이전 이미지 관련 검증은 과거 변경 기록입니다.

검증일: 2026-09-18

**자동 테스트 36개 통과: 게임 엔진 26개 + 화면 코드 연결 10개.**

## 실행 환경

로컬 Node JavaScript 런타임에서 실제 프로젝트 파일을 불러와 실행했습니다. 외부 테스트 패키지를 설치하지 않았습니다. 다음 명령으로 동일한 테스트를 재실행할 수 있습니다.

    node tests/run.cjs

게임 실행 자체에는 Node.js가 필요하지 않습니다.

## 장시간 시뮬레이션

고정 난수 시드와 1/120초 간격으로 36,000번 갱신하여 **게임 시간 5분**을 진행했습니다. 모든 좌표가 유한한 값으로 유지되고, 적·플레이어 탄환·적 탄환 개수가 제한된 범위 안에 머물렀습니다. 적 처치와 보스 격파가 실제로 발생했음을 확인했습니다.

이 검사는 무적 상태의 자동 조준 플레이어로 수행한 안정성 검사입니다. 사람이 플레이했을 때의 체감 난이도를 평가한 결과는 아닙니다.

## 실제 화면 검증 제한

Windows 자동화 도구가 현재 브라우저 URL을 확실하게 확인할 수 없다는 사유로 컴퓨터 사용을 중단했습니다. 따라서 **실제 브라우저 스크린샷, CSS 배치, 실제 모바일 기기, 오디오 출력은 확인하지 못했습니다.** DOM 모형 테스트와 Canvas 호출 검사는 통과했지만 실제 브라우저 검증을 대신하지 않습니다.

수동 확인할 항목:

- index.html을 열고 데스크톱·작은 화면에서 메뉴와 HUD가 겹치지 않는지 확인
- 스피커 버튼을 눌러 효과음 재생 및 음소거 확인
- 모바일에서 손가락 드래그와 두 번째 손가락의 DASH 사용 확인
- 편안하게·아케이드·하드코어 모드에서 보스까지 플레이하며 체감 난이도 확인

- 마우스 목표 지점에서 정지했을 때 대시 이동이 약해지던 문제
- 빠른 탄환이 프레임 사이에 적을 통과할 가능성
- 창 이탈·재시작 시 남는 입력과 강화 상태
- 일시정지 중 화면 흔들림이 이어질 수 있는 문제
- 효과음 재생 후 오디오 노드 연결 정리

## 체력바 변경 검증

하트 표시를 HP 체력바와 현재/최대 체력 숫자로 교체했습니다. 체력 비율에 따라 민트색·주황색·빨간색으로 표시되며, 좁은 화면에서는 막대 너비가 줄어듭니다.

기존 자동 테스트 36개가 통과했습니다. DOM 모형에서 3/3 → 피격 2/3 → 위험 체력 1/3 → 회복 2/3 → 난이도 변경 5/5 표시와 접근성 값을 추가 확인했습니다. 실제 브라우저 화면 검증 제한은 위와 같습니다.

## 회복 캡슐 개선 검증

20초마다 회복 캡슐을 공급하고, 초록색 십자 아이콘과 HP +1 라벨을 추가했습니다. 획득 시 실제 회복 여부에 맞춰 메시지와 체력바가 즉시 갱신됩니다. 최대 체력에서는 250점을 지급합니다. 기존 회복 아이템이 남아 있으면 정기 공급을 건너뜁니다.

기존 테스트 36개 통과. 정기 공급·중복 공급 방지·체력 1 회복·같은 아이템 중복 수령 방지·최대 체력 보상·일시정지·재시작 및 DOM 모형의 체력바/획득 메시지를 확인했습니다. 실제 브라우저 픽셀·오디오 출력은 이번 검증에 포함되지 않습니다.

## 플레이어 전투기 이미지 적용 검증

사용자 스크린샷을 내장 image_gen 도구로 편집하여 assets/player-fighter.png로 저장했습니다. 1254×1254 PNG의 RGBA 포맷과 모서리 알파 0을 확인했습니다. 원본 형태와 색상을 살리고 배경을 투명하게 정리했습니다.

기존 자동 테스트 36개 통과. DOM 모형에서 이미지 로딩 완료 시 52×52 drawImage 호출, 로딩 실패 시 기본 기체 표시, 좌우 화면 경계 여백을 확인했습니다. 기존 피격 판정 크기는 유지했습니다. 실제 게임 화면 스크린샷 검증 제한은 위와 같습니다.
