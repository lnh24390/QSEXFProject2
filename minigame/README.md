# NEON DRIFT 2.0 · 네온 드리프트

설치 없이 실행하는 네온 우주 슈팅 게임입니다. index.html을 Edge 또는 Chrome으로 열어주세요. 파일을 옮길 때는 styles.css, game-core.js, game.js, assets 폴더도 함께 옮겨야 합니다. 인터넷 없이 플레이할 수 있으며, 온라인일 때 웹 폰트가 적용됩니다.

VS Code에서는 이 폴더를 열고 **F5 → NEON DRIFT 플레이 / 디버깅**으로 실행할 수도 있습니다.

## 조작

| 기능 | 조작 |
| --- | --- |
| 이동 | 마우스, 방향키, WASD |
| 모바일 이동 | 화면을 누른 뒤 드래그. 손가락 위치로 순간이동하지 않는 상대 이동 방식 |
| 사격 | 자동 발사 |
| 대시 | Space / 모바일 DASH 버튼. 이동 방향으로 가속, 0.55초 무적, 3초 충전 |
| 일시정지 / 계속 | P, Esc, 게임 화면 왼쪽 위의 Ⅱ / ▶ 버튼 |
| 시작 / 재도전 | Enter 또는 화면 버튼 |
| 소리 | 상단 스피커 버튼. 기본 음소거 |
| 화면 효과 | 상단 ✦ 버튼. 화면 흔들림·광원·배경 움직임·입자를 줄임 |

탭이나 창을 벗어나면 자동으로 일시정지합니다. 일시정지 화면에서 메인 화면으로 돌아갈 수 있습니다.

본 게임은 게임 화면 내부의 난이도 선택창에 **NEON DRIFT · 네온 드리프트** 제목을 표시합니다. 난이도 버튼을 누르면 체력, 적의 속도, 일반 보스 수와 쉴드 등장 조건을 확인할 수 있습니다. 왼쪽 위 일시정지 버튼은 게임 시작 후 나타나며, 메뉴와 게임 종료 화면에서는 숨겨집니다.

| 난이도 | 시작 체력 | 전투 특징 | 일반 보스 | 쉴드 등장 |
| --- | --- | --- | --- | --- |
| 편안하게 | 5 | 느린 적, 여유로운 등장 간격 | 1대 | 15초마다 |
| 아케이드 | 3 | 기본 속도 | 1대 | 15초마다 |
| 하드코어 | 2 | 빠른 적, 짧은 등장 간격 | 1대 | 15초마다 |
| 불가능 | 1 | 하드코어와 같은 속도 | 2대 | 보스 한 대 격파마다 |

모든 난이도에서 10라운드마다 웨이브 보스는 한 대만 등장합니다.

## 2.0 업그레이드

- **난이도 4종**: 편안하게(목숨 5개), 아케이드(3개), 하드코어(2개), 불가능(1개). 최고 점수는 난이도별로 저장합니다.
- **콤보**: 3.5초 안에 연속 처치. 5처치마다 배율이 증가해 최대 5배. 피격 또는 시간 만료 시 초기화합니다.
- **적 3종**: 정찰기, 중장갑기, 플레이어를 조준하는 사격기.
- **강화 아이템**: 9처치마다 확산탄(W) → 회복(+) 순서로 등장합니다. 확산탄은 10초, 보호막은 모든 난이도에서 15초 동안 유지되며 피격 1회를 막으면 즉시 사라집니다. 다시 획득하면 지속시간을 15초로 갱신합니다. 체력이 가득 찬 상태에서 회복을 얻으면 250점을 받습니다.
- **회복 캡슐**: 20초마다 초록색 + 캡슐이 등장합니다. 가까이 가면 끌려와 획득되며 체력을 1 회복합니다. 화면에 회복 아이템이 남아 있으면 정기 공급은 건너뜁니다. 기존 처치·보스 보상으로도 획득할 수 있습니다.
- **보스전**: 30초에 센티널 등장. 부채꼴 탄막과 체력 45% 이하에서 추가 조준 사격. 격파 후 30초 뒤 다음 보스가 등장합니다.
- **결과 화면**: 생존 시간, 격파 수, 최대 콤보, 보스 격파 수, 크리스털 획득 수.
- **조작 안정화**: 일정한 간격의 물리 연산, 빠른 탄환의 이동 경로 충돌 판정, 대시 방향 고정, 멀티터치 간섭 방지, 재시작 초기화.

정찰기 50점, 사격기 100점, 중장갑기 150점, 크리스털 100점, 보스 2,500점에 현재 콤보 배율을 적용합니다. 20초마다 섹터가 상승합니다.

## 테스트

게임 실행에는 Node.js가 필요 없습니다. 자동 테스트를 다시 실행하려면 Node.js 18 이상에서 다음 명령을 실행합니다. 외부 패키지 설치는 필요 없습니다.

    node tests/run.cjs

검증 범위와 남은 수동 확인 항목은 TEST-REPORT.md에 기록했습니다. DOM 모형 테스트는 브라우저의 실제 CSS 배치, 픽셀 출력, 음성 출력을 검증하지 않습니다.

최고 점수와 설정은 브라우저의 로컬 저장소에 보관합니다. 저장소가 제한된 환경에서도 게임은 실행되지만 기록이 유지되지 않을 수 있습니다.

## 플레이어 전투기

현재 플레이어 이미지는 HTML에서 지정한 프로젝트 루트의 **전투기.png**를 사용합니다. 프로젝트를 옮길 때 이 파일도 함께 복사해주세요. 플레이어에 52×52 크기로 표시하며 엔진 불꽃, 기울기, 보호막, 대시 효과와 함께 그립니다. 로딩 중이거나 파일을 읽지 못하면 기본 기체를 표시합니다.

- 불가능 난이도는 보스가 2대씩 동시에 등장합니다. 체력바는 왼쪽·오른쪽 보스별로 각각 표시하며, 모두 격파한 뒤 30초 후 다음 보스전이 시작됩니다.

- 보호막(S) 등장: 불가능 모드는 보스 1대 격파마다 1개, 나머지 모드는 게임 시간 15초마다 1개씩 등장합니다.

- 모든 난이도에서 웨이브 보스(10, 20, 30...라운드)를 격파할 때마다 MAX HP +1 아이템이 생성됩니다. 1라운드와 일반 보스전에서는 생성되지 않습니다. 획득 시 최대·현재 체력이 1씩 증가하며, 생성 후 게임 시간 5초 안에 획득하지 않으면 사라집니다. 새 게임에서 체력은 초기화됩니다.

- 10라운드마다(10, 20, 30...) 모든 난이도에서 3-WAVE BOSS 1대만 등장합니다. 불가능에서도 해당 라운드는 1대이며, 하늘색·노란색·보라색의 독립 체력바 3개를 가집니다. 각 색깔의 체력은 바로 이전 라운드 일반 보스 한 대의 최대 체력과 동일하며, 현재 색의 체력이 0이 되면 다음 웨이브로 넘어가고 세 색을 모두 소진해야 격파됩니다. 1단계: 아래로 직선 연사(0.15초), 2단계: 기존 보스의 5발 부채꼴 발사(1.05초), 3단계: 같은 부채꼴을 0.15초마다 발사합니다. 라운드는 보스전 전체를 클리어할 때마다 1씩 증가합니다.

- 웨이브 보스는 1→2, 2→3단계 전환마다 확산탄·보호막·회복을 각각 1개씩 떨어뜨립니다. 최대 체력 아이템은 전환 보상에 포함되지 않으며, 최종 격파 시에는 기존 격파 보상만 지급됩니다.

## Android APK

**android/NeonDrift-2.0.0-debug.apk**는 본 게임을 포함한 디버그 서명 APK입니다. Android 8.0 이상에서 설치할 수 있습니다. 네트워크 권한 없이 게임 파일을 앱 안에서 실행합니다.

재빌드에는 JDK와 공식 Android 빌드 도구가 필요합니다. 빌드 스크립트가 필요한 Android 도구를 내려받고 체크섬을 확인합니다. JDK의 bin 폴더가 PATH에 있는 PowerShell에서 실행하세요.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\android\build.ps1 -ToolCache "$env:TEMP\NeonDriftBuild"
```

같은 서명으로 업데이트하려면 ToolCache 안의 `neon-drift-debug.keystore`를 보관해야 합니다. 빌드 과정에서 APK 서명과 ZIP 정렬을 검사하고, dist 폴더에 SHA-256 파일도 생성합니다.

현재 설치용 APK는 `android` 폴더에 있습니다. 빌드 스크립트를 다시 실행하면 새 APK는 `dist` 폴더에 생성됩니다.
