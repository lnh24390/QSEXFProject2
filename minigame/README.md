# NEON DRIFT 2.0 · 네온 드리프트

설치 없이 실행하는 네온 우주 슈팅 게임입니다. index.html을 Edge 또는 Chrome으로 열어주세요. 파일을 옮길 때는 styles.css, game-core.js, game.js, assets 폴더도 함께 옮겨야 합니다. 인터넷 없이 플레이할 수 있으며, 온라인일 때 웹 폰트가 적용됩니다.

VS Code에서는 이 폴더를 열고 **F5 → NEON DRIFT 플레이 / 디버깅**으로 실행할 수도 있습니다.

## 조작

| 기능 | 조작 |
| --- | --- |
| 이동 | 마우스, 방향키, WASD |
| 모바일 이동 | 화면을 누른 뒤 드래그. 손가락 위치로 순간이동하지 않는 상대 이동 방식 |
| 사격 | 자동 발사 |
| 대시 | Space / 모바일 DASH 버튼. 이동 방향으로 가속, 0.55초 무적, 3초 충전 |
| 일시정지 / 계속 | P, Esc, 상단 일시정지 버튼 |
| 시작 / 재도전 | Enter 또는 화면 버튼 |
| 소리 | 상단 스피커 버튼. 기본 음소거 |
| 화면 효과 | 상단 ✦ 버튼. 화면 흔들림·광원·배경 움직임·입자를 줄임 |

탭이나 창을 벗어나면 자동으로 일시정지합니다. 일시정지 화면에서 메인 화면으로 돌아갈 수 있습니다.

## 2.0 업그레이드

- **난이도 3종**: 편안하게(목숨 5개), 아케이드(3개), 하드코어(2개). 최고 점수는 난이도별로 저장합니다.
- **콤보**: 3.5초 안에 연속 처치. 5처치마다 배율이 증가해 최대 5배. 피격 또는 시간 만료 시 초기화합니다.
- **적 3종**: 정찰기, 중장갑기, 플레이어를 조준하는 사격기.
- **강화 아이템**: 9처치마다 확산탄(W) → 보호막(S) → 회복(+) 순서로 등장합니다. 확산탄은 10초, 보호막은 피격 1회를 막습니다. 체력이 가득 찬 상태에서 회복을 얻으면 250점을 받습니다.
- **회복 캡슐**: 20초마다 초록색 + 캡슐이 등장합니다. 가까이 가면 끌려와 획득되며 체력을 1 회복합니다. 화면에 회복 아이템이 남아 있으면 정기 공급은 건너뜁니다. 기존 처치·보스 보상으로도 획득할 수 있습니다.
- **보스전**: 45초에 센티널 등장. 부채꼴 탄막과 체력 45% 이하에서 추가 조준 사격. 격파 후 45초 뒤 다음 보스가 등장합니다.
- **결과 화면**: 생존 시간, 격파 수, 최대 콤보, 보스 격파 수, 크리스털 획득 수.
- **조작 안정화**: 일정한 간격의 물리 연산, 빠른 탄환의 이동 경로 충돌 판정, 대시 방향 고정, 멀티터치 간섭 방지, 재시작 초기화.

정찰기 50점, 사격기 100점, 중장갑기 150점, 크리스털 100점, 보스 2,500점에 현재 콤보 배율을 적용합니다. 20초마다 섹터가 상승합니다.

## 테스트

게임 실행에는 Node.js가 필요 없습니다. 자동 테스트를 다시 실행하려면 Node.js 18 이상에서 다음 명령을 실행합니다. 외부 패키지 설치는 필요 없습니다.

    node tests/run.cjs

검증 범위와 남은 수동 확인 항목은 TEST-REPORT.md에 기록했습니다. DOM 모형 테스트는 브라우저의 실제 CSS 배치, 픽셀 출력, 음성 출력을 검증하지 않습니다.

최고 점수와 설정은 브라우저의 로컬 저장소에 보관합니다. 저장소가 제한된 환경에서도 게임은 실행되지만 기록이 유지되지 않을 수 있습니다.

## 플레이어 전투기

현재 플레이어 이미지는 프로젝트 루트의 **전투기-배경제거.png**를 사용합니다. 원본 **전투기.png**는 보관했습니다. 프로젝트를 옮길 때 배경 제거 파일도 함께 복사해주세요. 플레이어에 52×52 크기로 표시하며 엔진 불꽃, 기울기, 보호막, 대시 효과와 함께 그립니다. 로딩 중이거나 파일을 읽지 못하면 기본 기체를 표시합니다. 이전 편집 이미지 assets/player-fighter.png는 보관만 하며 현재 플레이어에는 사용하지 않습니다.
