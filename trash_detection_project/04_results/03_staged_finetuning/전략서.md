# 1차 결과에서 이어가는 단계별 전이학습 전략

## 출발점과 보존 범위

사용자의 최신 지시에 따라 YOLO26m 작업을 중단했다. m의 마지막으로 저장된 에포크, best/last 가중치와 원시 로그는 MODEL_SCALING_20260913에 보존하며 다음 분할 m 작업도 실행하지 않는다. 중단 시 진행 중이던 에포크의 미저장 업데이트는 포함되지 않는다.

이번에는 **1차 전이학습 결과의 best.pt**에서 시작한다. 검출 모델은 YOLO26s, 분할 모델은 YOLO11n-seg다. 원래 best_train으로 되돌아가거나 m으로 크기를 바꾸지 않는다. 각 출발점은 checkpoints에 복사하고 원본과 SHA256을 비교한다. 1차 학습의 optimizer를 복원하는 resume가 아니라, 같은 구조의 가중치를 가져와 단계별 새 optimizer·학습률로 미세조정하는 방식이다. 한 단계가 중단된 경우에는 그 단계의 last.pt로 optimizer까지 복원하여 이어간다.

원본 best_train, 1차 전이학습, 중단한 m 실험을 모두 보존한다. 이번 결과가 더 좋아졌다고 검증되기 전에는 배포 모델을 교체하지 않는다.

## 기존 결과와 가설

첫 전이학습은 검출 시험 mAP50–95가 76.11→68.14, 분할 마스크는 68.66→68.20으로 하락했다. 평균 성능 회복과 신규 취약 사례 개선을 구분해서 확인해야 한다.

시작 편향 학습률만 낮춘 대조 실험과 BN 통계만 복원한 대조 실험은 회복에 실패했다. 따라서 어느 한 설정을 주원인으로 확정하지 않는다. 기존 데이터 일부만 재사용한 분포 변화, 최적화 및 YOLO26 손실 일정과 증강의 상호작용은 남은 가설이다. 이번 단계 구성은 검증할 전략이지 개선을 보장하는 처방이 아니다.

## 단계별 설정

| 단계 | 목적 | 층 고정 | 학습률 | Mosaic | 흐림 |
|---|---|---|---:|---:|---|
| 2차 | 기존 성능 회복을 위한 안정적 조정 | 앞 10개 블록 고정 | 0.00003 | 0 | 없음 |
| 3차 | 전체 특징 조정 및 취약 사례 보강 | 전체 학습 | 0.00001 | 0.1 | 10% 확률, 약한 3픽셀 흐림 |
| 마지막 미세조정 | 박스·외곽선 정확도 조정 | 전체 학습 | 0.000005 | 0 | 없음 |

공통: 640, batch 16, workers 4, AMP, GPU 단독 실행, AdamW, warmup_bias_lr=0, warmup_epochs=1, 최대 100에포크, patience=10. 학습률은 cosine 방식으로 단계의 시작 값에서 감소한다. 단계별 정확한 설정은 configs에 보존한다.

2차의 고정된 블록은 가중치뿐 아니라 해당 BatchNorm의 통계 업데이트도 막는다. 설치된 Ultralytics의 고정 처리에 더해 첫 배치에서 실제 적용 여부를 확인한다. 전체 층을 고정하거나 원본 모델의 통계를 강제로 덮어쓰는 방식은 아니다.

3차의 흐림은 좌표를 바꾸지 않는 Gaussian/Motion blur이며 작은 전지의 세부 정보가 과하게 사라지지 않도록 강도를 제한한다. dropout은 검출·분할 정규화로 사용하지 않는다. 마지막 단계는 최대 에포크에 도달해야만 시작하는 close_mosaic에 의존하지 않고, 별도의 무 Mosaic 실험으로 실행한다.

## 데이터와 라벨

기존 자료를 일부만 뽑았던 첫 실험과 달리, 각 과제의 기존 train 전체와 확보된 신규 자료를 사용한다. 검출 고유 train은 53,103장, 분할은 50,180장이다. 두 과제의 공통 기존 train 47,054장이 중심이며 과제 고유 train도 포함한다. 각 과제의 val/test ID는 train에 들어가지 않는다.

2차와 마지막 단계는 목록 중복 없이 전체 train을 사용한다. 3차만 천 수건·종이/비닐 포장재·건전지·모니터/교실 배경·일반쓰레기 실제 사진 등 검증된 학습 후보에 제한된 추가 노출을 준다. 신규 독립 이미지를 확보한 것으로 세지 않는다. 정확한 대상과 반복 횟수는 data/*_hard_selection.json 및 reports/data_manifest.json에 남긴다.

이미지는 기존 새 데이터셋의 640×640 압축 JPEG를 참조한다. EXIF/GPS/XMP/ICC/주석 제거 전수 검증 결과를 재사용하고 표본을 재확인한다. 이미지·라벨·증강 파일을 새 폴더에 중복 생성하지 않는다. 출처·라이선스는 기존 sources/reports에 유지한다. bbox와 seg의 클래스 ID가 다르므로 각각의 라벨 순서를 그대로 사용한다.

오염도·지역 배출 규정 때문에 재질 클래스를 바꾸지 않는다. 천 수건은 general, 종이 기반 코팅지는 paper이고 모니터는 일곱 클래스 밖 배경이다. bbox만 있는 데이터에 가짜 사각형 마스크를 만들어 seg에 넣지 않는다.

## 다음 단계로 넘어가는 기준

각 단계의 입력 모델과 후보를 **동일한 고정 val**에서 비교한다. 검출 기준 점수는 박스 mAP50–95, 분할은 박스+마스크 mAP50–95 합이다.

후보는 다음 조건을 모두 만족할 때만 다음 단계의 출발점으로 채택한다.

1. 기준 점수가 0.0001보다 크게 상승한다.
2. 박스·마스크 각각의 평균 mAP가 입력보다 0.0001 이상 낮아지지 않는다.
3. 각 클래스 AP의 하락이 입력 대비 1%p 이내다.

이 수치는 사전에 고정한 운영 기준이며 통계적 유의성을 뜻하지 않는다. 조건을 만족하지 못한 후보는 별도 run에 보존하고, 다음 단계는 이전에 선택된 입력 가중치로 진행한다. 이때도 최초 계보는 사용자가 지정한 1차 전이학습 결과다.

조기 종료의 기준도 단계 입력 모델의 val 점수에서 시작한다. 10에포크 동안 입력 또는 이후 최고 점수를 넘지 못하면 해당 단계를 종료한다. 새 run 안에서만 가장 좋은 점수를 얻었다는 이유로 채택하지 않는다. 성능 하락 여부는 매 에포크 기록하며, 최종 채택은 재검증한 후보 기준이다.

1차 결과보다 회복했는지와 원래 best_train보다 개선됐는지는 별개다. 마지막에 두 기준과 클래스별 지표를 모두 보고한다. 어떤 단계도 모든 클래스의 개선을 보장하지 않는다.

## 실행 순서와 기록

**검출 2차 → 검출 3차 → 검출 마지막 미세조정 → 검출 최종 평가 → 분할 2차 → 분할 3차 → 분할 마지막 미세조정 → 분할 최종 평가** 순서로 GPU 작업을 하나씩 실행한다. 오류가 나면 뒤의 작업을 시작하지 않는다.

매 에포크 시간, 손실, 검증 점수, 입력 대비 개선 여부를 JSON과 원시 로그에 기록한다. 학습 중에는 약 1분 간격으로 현재 상태와 진행보고서를 갱신한다. 각 단계 완료 시 입력·후보·선택된 가중치 경로와 해시, 채택 이유, 클래스별 AP를 기록한다. 출발점·설정 변경·중단·실패·완료 이벤트는 events.jsonl에 이어서 쓴다.

본 학습은 분리된 숨김 프로세스로 실행하므로 대화가 끝나도 계속된다. PC 종료·재부팅 시에는 중단될 수 있으며 재개할 때 last.pt를 확인한다. 첫 에포크와 재개 직후 에포크는 시간 평균에서 별도로 표시한다. 전체 데이터와 세 단계로 진행하므로 s 모델이어도 짧은 첫 전이학습만큼 빨리 끝난다고 보장하지 않는다. 실제 에포크 시간으로 예상 시간을 갱신한다.

시험 자료는 단계별 설정과 가중치 선택에 사용하지 않는다. 각 과제의 최종 후보만 시험한다. 기존 시험 결과를 이미 열람했다는 한계와 한국 현장·흐림·수건·코팅지의 별도 미학습 평가 부족을 명시한다. 학습 자료의 점수 상승을 새로운 현장 인식률 상승으로 표현하지 않는다.

근거: [Ultralytics 학습 설정·freeze·patience·resume](https://docs.ultralytics.com/modes/train/), 설치된 Ultralytics 8.4.146의 BaseTrainer._model_train 및 체크포인트 처리 코드, 기존 프로젝트의 실측 로그와 평가 JSON.
