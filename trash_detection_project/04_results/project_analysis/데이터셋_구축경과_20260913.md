## 2. 목표와 라벨링 원칙의 수정

처음에는 빠른 추가 학습과 기존 성능 유지가 논의되었으나, 사용자는 가중치의 실질적인 인식 성능 향상을 우선한다고 정정했다. 목표를 기존 품목 성능을 유지하면서 새로운 상태·재질·유사 물체 오인식을 줄이는 전이학습으로 바꾸었다.

초기 배출 규정 중심의 분류안은 사용자 지시에 따라 폐기했다. 오염된 비닐은 vinyl, 오염된 플라스틱은 plastic, 깨진 유리는 glass다. 지역별 배출 안내는 앱이 맡는다. 사진으로 확정할 수 없는 복합재질을 general로 몰아넣지 않는다.

## 3. 최초 자료 확보와 기존 라벨 점검

TACO 공식 객체 주석을 확보하고 기존 s3_taco 출처와 대조했다. TACO 1,500장 중 825장은 기존 자료이므로 신규로 세지 않았다. 새로운 675장 중 처음 299장을 개별 URL로 받았고, 실패한 376장은 공식 Zenodo 압축본으로 복구했다.

기존 bbox 1,732개, seg 1,064개 객체가 원본 주석과 좌표로 대응되었다. 재질·품목 기준에 따라 새 사본의 bbox 132개, seg 66개 객체 클래스가 변경되었다. 이는 전체 이미지의 육안 검수 완료를 의미하지 않는다. 기존 좌표·분할·객체 수 보존과 클래스 수정 로그를 검증했다.

새 TACO 사진 중 300장/874개 객체를 bbox와 polygon에 반영했다. 375장은 미확정 품목, 형상/좌표 문제, 원본 주석 누락 의심 또는 유사 이미지 후보 등으로 보류했다. 신규 TACO와 기존 TACO 간 지각 해시 점검에서 1건의 유사 후보를 보류했다. 별도로 Commons 사진 6장은 직접 확인해 bbox를 작성했다.

## 6. 증강·Dropout 팩트체크와 방향 결정

설치된 Ultralytics 8.4.146 코드와 공식 문서를 확인했다. dropout 인자는 classify용이며, 현재 표준 detect/segment 모델에 dropout=0.1을 넣는 것으로 드롭아웃 층이 생기지 않는다. 이번 전이학습에는 추가하지 않는다. 내장 Mosaic은 과적합 완화 수단이며 정확도나 일반화를 보장하지 않는다. [공식 학습 인자](https://docs.ultralytics.com/modes/train/), [공식 증강 안내](https://docs.ultralytics.com/guides/yolo-data-augmentation/)를 근거로 삼았다.

640 모델 가중치는 960 입력으로 추가 학습할 수 있지만, 사용자 최종 결정은 속도와 파일 용량을 고려한 640이다. 960 제안은 철회해 retired_960_not_used에 기록만 남겼다. 원본을 미리 모자이크로 합치는 방식은 정식 학습 자료에 적용하지 않았다. 설명용 미리보기와 속도 비교용 고정 모자이크만 reports/benchmarks에 분리해 만들었다.

## 7. 기존 가중치 복사

best_train 안의 완료된 bbox_yolo26s_nobg/weights/best.pt, seg_yolo11n/weights/best.pt를 checkpoints에 복사했다. bbox_yolo11n은 기준 비교용으로 함께 복사했다. SHA-256 동일성과 각 모델의 일곱 클래스 순서를 확인했다. 짧게만 학습된 seg_yolo26s_nobg를 완료된 모델로 간주하지 않았다.

전이학습은 복사한 기존 best.pt로 초기화하고 resume=False로 새 최적화 상태를 시작한다. 원래 학습 결과나 기존 best.pt를 덮어쓰지 않는다. 속도 비교에서 임시 갱신한 가중치는 실제 전이학습의 시작점으로 사용하지 않는다.

## 8. 640 변환·압축·메타데이터 제거

종횡비를 유지해 640×640으로 리사이즈하고 남는 공간에 114색 여백을 넣었다. 실제 반올림된 가로·세로 크기와 여백에 맞춰 bbox 중심/크기와 polygon의 모든 점을 변환했다. 이미지 회전이나 자르기를 임의로 넣지 않았다.

JPEG 품질 85, optimize=True, 색차 서브샘플링으로 저장했다. 변환 당시 원본을 별도로 두고 학습 사본의 EXIF/GPS·XMP·ICC·주석 부가정보를 제거했다. 출처·라이선스는 외부 manifest에 남겼다. JPEG 포맷 해석에 필요한 기본 헤더까지 없애는 의미는 아니다.

검출 사본 65,460개와 분할 사본 62,536개, 총 127,996개 출력에서 640 크기와 메타데이터 제거를 확인했다. 논리적 파일 용량은 21.21GB → 10.68GB다. 하드링크/중복 포함 파일 길이의 합으로, 실제 디스크 점유량이나 독립 원본 수와는 다르다.

## 9. 기존 자료와 추가 자료의 혼합

두 과제의 공통 train 후보는 47,054장이다. 공통 원본 6,444장과 공통 배경 677장을 선별했다. 공통 후보로 클래스 분포가 충족되지 않을 때만 해당 모델의 고유 train 자료로 보완하도록 구현했다. 현재 고유 보완은 bbox 0장, seg 0장이다. 각 모델 자체의 val/test 원본 ID가 train에 들어간 건수는 0이다.

## 10. 실제 속도 비교

RTX 4060, 640, batch 16, workers 4, AMP 조건에서 복사 가중치로 짧은 학습 스텝 속도를 순차 측정한다. 동일한 512개 train 원본 풀을 사용한다. 첫 에포크는 준비 시간으로 제외하고 다음 두 에포크의 처리량을 합산한다. Mosaic 외 기하 변환은 비교 동안 0으로 두고 밝기·색·좌우반전은 동일하게 유지한다.

고정 모자이크는 내장 Mosaic+기하 처리의 한 번 생성된 결과를 JPEG로 저장한 것이다. 실행 중에는 그 합성을 생략한다. 사전 생성 시간과 추가 저장 용량은 별도 기록한다. 고정된 조합의 반복과 매번 달라지는 조합은 일반화 효과가 같지 않으므로 짧은 속도 측정으로 정확도 우열을 단정하지 않는다.

| 과제 | 방식 | 학습 스텝 이미지/초 | 최대 GPU 할당 MiB |
|---|---|---:|---:|
| bbox | YOLO 내장 Mosaic | 83.38 | 4290 |
| bbox | 고정 모자이크 사전 생성 | 83.40 | 4290 |
| bbox | Mosaic 미사용 | 83.16 | 4287 |
| seg | YOLO 내장 Mosaic | 124.38 | 2435 |
| seg | 고정 모자이크 사전 생성 | 129.16 | 2429 |
| seg | Mosaic 미사용 | 129.17 | 2417 |

이 수치는 검증·저장·긴 학습의 데이터 로딩 변동을 포함한 에포크 전체 속도가 아니다. 표에 없는 조합은 아직 결과 파일이 없다. 실제 학습 시간과 mAP는 이후 로그로 확인한다.

## 11. 순차 전이학습과 현재 상태

현재 상태: `complete`. Both models trained sequentially and compared to original checkpoints

검출 → 분할 순서이며 GPU 학습을 동시에 실행하지 않는다. 기본 후보는 640, batch 16, workers 4, AMP, AdamW, 초기 학습률 0.0001, 최대 100에포크, patience 10, 기존 가중치 전체 미세조정이다. 내장 Mosaic 후보는 0.5이며 마지막 5에포크에 끈다. 실제 선택 설정과 시작·종료 상태를 finetune_state.json 및 실행 로그에 남긴다.

검증으로 best를 선택하고 기존 원본 모델과 같은 과제의 같은 평가 자료로 비교한다. 각 과제 test를 바꾸어 사용하지 않는다. 전체/클래스별 mAP 및 오탐을 측정하기 전에는 인식률이 개선됐다고 주장하지 않는다. 별도 오인식 사례 평가는 표본이 작아 전체 정확도의 대체 지표가 될 수 없다.

## 12. 남은 검수와 한계

- 형식·좌표 검증과 출처 주석 매핑은 완료 범위를 기록했지만, 기존 전체 및 신규 출처 사진을 모두 눈으로 검수한 것은 아니다. raw 후보는 학습 목록에 자동 포함하지 않는다.
- 코팅 종이, 구겨진/젖은 수건, 실제 모니터+종이/전지 혼합 장면의 충분한 독립 평가 자료가 아직 부족하다.
- 기존 원본의 생성 증강 및 비슷한 장면 중복은 알려진 그룹을 따라 다룬다. 출처 간 모든 의미적 유사성을 전수 보장하지 않는다.
- 이미지 압축은 손실 방식이다. 파일 크기를 최소화하는 절대 최적값을 찾았다는 의미가 아니며, 품질 85를 용량·세부 표현의 실용적 절충으로 사용했다.
- 새 자료의 한국 현장 적합성과 물체 다양성, 클래스별 개선 여부는 별도 실물 평가가 필요하다.

## 15. 최종 정리와 교실 배경 보강

앞의 수집 표는 확보 당시 이력이다. 변환하지 않은 후보·출처 시험 사진은 현재 학습 데이터에 남아 있지 않다. 최종 640 JPEG는 두 과제 합계 128,008파일, 논리적 파일 용량 10.68GB다. 모든 파일의 크기·메타정보 제거·라벨 쌍을 확인했다. 이 수량은 선택된 학습 목록보다 크며 전체 변환 사본과 val/test를 포함한다.

밝은 벽과 검은 모니터가 있는 컴퓨터실·교실 등 직접 검수한 배경 5장을 양쪽에 추가했고, 기존 모니터 배경 2장도 seg에 반영했다. 새 배경은 총 7장이다. 사진 내 대상 쓰레기가 보이는 후보는 빈 라벨로 넣지 않았다.

영구 삭제는 자동 승인 검토에서 거부되어 휴지통 정리를 사용했다. staged_bbox만 Windows 권한 오류로 휴지통 이동이 실패해 프로젝트 work/cleanup_recovery_20260913/staged_bbox로 격리했다. 이 복구용 사본은 새 데이터셋 외부에 남아 있으며 학습에 사용하지 않는다. 휴지통과 복구용 사본의 디스크 용량이 모두 해제됐다는 의미는 아니다.

## 16. 일반쓰레기·포장재·흐림 보강

기존 원본 선택에서 생성 이미지보다 실제 촬영 자료를 우선하도록 보완했다. 공통 기존 자료의 생성 증강 이미지 선택은 411장에서 181장으로 줄었다. 일반쓰레기 실제 사진을 각 과제에서 에포크당 400회 추가 노출한다. bbox는 신규 일반쓰레기 76회, 종이·비닐 포장재 200회, 신규 배경 14회를 추가 노출한다. 이는 목록 반복이며 파일 복제나 새 독립 이미지 확보가 아니다. 최종 bbox는 고유 10,350장/에포크 11,040항목, seg는 고유 7,428장/에포크 8,442항목이다.

학습 중에만 15% 확률로 약한 Gaussian/Motion blur 중 하나를 적용하고 8% 확률로 JPEG 품질 75~95 압축 효과를 적용한다. 좌표를 움직이지 않는 변환이며, 증강 이미지는 디스크에 저장하지 않는다. 기본 JPEG 품질 85와 별개의 학습 효과다. runtime_augmentation_validation.json에서 라벨 보존과 설정 직렬화 복원을 확인한다. 검증·시험 사진에는 이 랜덤 증강을 적용하지 않는다. 실제 흐림 현장 성능 개선은 아직 측정하지 않았다.

앞의 속도 비교는 SGD 기반 짧은 학습 스텝 측정이며 실제 전이학습은 AdamW다. 전체 학습의 검증·저장 시간도 있으므로 실제 에포크 기록으로 소요 시간을 확인한다. 내장 Mosaic 0.5를 유지하고 검출/분할에 classify 전용 dropout은 넣지 않는다.
