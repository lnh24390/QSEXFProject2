# 통합 모델 분석 결과

| 폴더 | 내용 |
|---|---|
| `evaluations/bbox/<출처>/<실행 ID>` | 새로 측정한 검출 평가 |
| `evaluations/seg/<출처>/<실행 ID>` | 새로 측정한 분할 평가 |
| `comparisons/<실행 ID>` | 같은 조건 모델의 전체·클래스별 비교 |
| `historical/<실행 ID>` | 기존 보고서에서 가져온 평가와 CSV 기반 학습 요약 |
| `training/<프로젝트>/<실행 ID>` | 이후 학습 완료 시 생성할 공통 요약 |

새 평가 결과와 과거 결과를 구분합니다. 각 실행 폴더의 JSON이 기준 자료이며 CSV와 Markdown은 읽기 위한 표현입니다.
프로젝트별 원본 가중치·로그·보고서는 한 단계 위의 기존 폴더에 있습니다. 파일 이동·가중치 복사 없이 함께 참조합니다.
검출과 분할은 테스트 구성이 달라 별도의 비교표를 봐야 합니다.

평가·외부 모델 추가 방법: [공통 분석 사용법](../../02_training/model_analysis/README.md).

`reviews/<실행 ID>`에는 과제별 종합 분석이 있습니다. [초기 학습 모델 종합 분석](reviews/20260914T093059245267Z_initial_training_9158da7c/summary.md).
