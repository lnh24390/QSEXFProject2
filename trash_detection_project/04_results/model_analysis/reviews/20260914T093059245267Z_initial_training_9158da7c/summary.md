# 02_training 모델 종합 분석

분석일: 2026-09-14. 초기 학습 산출물은 04_results/baseline_training/runs에 있으며 02_training의 코드가 해당 위치를 참조합니다.

**완료 모델은 검출 YOLO11n·YOLO26s와 분할 YOLO11n-seg 총 3개입니다.** 중단된 검출 1개와 분할 1개는 참고 후보로 따로 표시합니다.

같은 과제 안에서는 공통 test 2,734장, 640, batch 16, FP32, conf 0.001, IoU 0.7로 비교했습니다. 이미 같은 조건으로 평가된 동일 해시 모델 2개는 결과를 재사용했고 나머지 3개를 새로 평가했습니다. 가중치·데이터 변경 및 학습 재시작은 없습니다.

## 전체 결과

mAP50–95는 %입니다. 배경 오탐은 공통 배경 150장 중 confidence≥0.25의 예측이 하나 이상 발생한 이미지 수입니다.

|---|---|---:|---:|---:|---:|---:|
| YOLO11n 검출 · 배경 포함 | 완료 / 100 | 92 | 72.76 | — | 2/150 | 5.23 |
| YOLO26s 검출 · 배경 제외 | 완료 / 100 | 90 | 76.11 | — | 37/150 | 19.39 |
| YOLO26s 검출 · 1에포크 중단 | 중단 / 1 | 1 | 56.12 | — | 81/150 | 57.46 |
| YOLO11n-seg · 배경 포함 | 완료 / 100 | 96 | 74.39 | 68.66 | 0/150 | 5.74 |
| YOLO26s-seg · 4에포크 중단 | 중단 / 4 | 1 | 59.48 | 55.81 | 74/150 | 66.05 |

중단된 실험의 best.pt에는 optimizer와 EMA 상태가 포함되어 파일이 더 큽니다. 표의 파일 용량은 저장된 체크포인트 크기이며 배포용 가중치 크기와 구분해야 합니다.

## 해석

1. 완료된 검출끼리 비교하면 YOLO26s가 YOLO11n보다 박스 mAP50–95가 약 3.35%p 높고 7개 클래스 모두 높습니다. 다만 배경 오탐 이미지는 2장 → 37장으로 증가했습니다. 정확도 우위와 배경 오탐 문제를 동시에 고려해야 합니다.
2. YOLO26s 배경 오탐 43건 중 비닐 17건, 플라스틱 10건, 배터리 7건이 많았습니다. 기존에 말씀하신 비닐·배터리 오인식과 관련된 보강 우선순위를 뒷받침하지만 이 배경 세트 자체가 수건·모니터 전용 독립 평가 세트는 아닙니다.
3. YOLO11n-seg는 마스크 mAP50–95 68.66%이고 이번 배경 150장에서 오탐이 0건이었습니다. 표본에서 0건이라는 뜻이며 실제 환경에서도 오탐이 전혀 없다는 뜻은 아닙니다.
4. YOLO26s-seg는 4에포크에서 사용자 결정으로 중단됐고 best는 1에포크 가중치입니다. 박스 59.48%, 마스크 55.81%, 배경 오탐 74/150입니다. 이 값으로 충분히 학습한 YOLO26s-seg의 최종 성능을 판단할 수 없습니다.
5. 1에포크 검출 실험은 박스 56.12%, 배경 오탐 81/150입니다. 이후 100에포크를 완료한 YOLO26s와 구분해야 하며 최종 모델 후보로 권하지 않습니다.
6. 검출·분할은 라벨 데이터 분할이 달라 서로 mAP 순위를 매기지 않습니다. 배경 비교에 사용한 150장만은 이미지 내용 해시가 전 모델에서 동일함을 확인했습니다.
7. 두 검출 모델은 모델 크기·배경 포함 여부·patience가 함께 다릅니다. 정확도나 오탐 차이를 배경 데이터 하나의 효과로 단정할 수 없습니다.

## 전이학습 결과와 연결

검출 YOLO26s: 초기 76.11 → 1차 68.14 → 최종 74.11%. 후속 학습으로 회복했지만 초기보다 2.00%p 낮습니다. 최종 전이학습은 초기 YOLO11n 검출(72.76%)보다는 높지만 출발 모델 YOLO26s보다 좋아졌다고 볼 수 없습니다.
분할 YOLO11n-seg 마스크: 초기 68.66 → 1차 68.20 → 최종 68.71%. 0.05%p 차이는 확실한 개선으로 해석하지 않습니다.
