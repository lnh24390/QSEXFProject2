# 성능 하락 분석과 두 번째 학습 전략

## 1. 첫 실험 결과와 판단

기존 모델과 첫 전이학습 모델을 각 과제의 동일한 시험 자료로 비교했다. bbox와 seg는 자체 분할이 다르므로 두 모델의 수치를 직접 우열 비교하지 않는다.

| 과제·지표 | 기존 모델 | 첫 전이학습 | 변화(%p) |
|---|---:|---:|---:|
| YOLO26s bbox mAP50–95 | 76.11 | 68.14 | -7.97 |
| YOLO11n-seg bbox mAP50–95 | 74.39 | 73.32 | -1.07 |
| YOLO11n-seg mask mAP50–95 | 68.66 | 68.20 | -0.47 |

검출은 모든 클래스의 시험 AP가 하락했다. 특정 새 품목만의 문제가 아니라 기존 표현 보존에 실패했을 가능성을 우선 조사한다. 검출의 원래 val mAP50–95는 84.92, 첫 에포크는 69.56, 새 실험에서 가장 높은 val은 79.92였다. 검증에서 이미 원본보다 낮았으므로 신규 run 내부의 best.pt라는 이유만으로 배포 후보가 되어서는 안 된다.

## 2. 확인된 설정 위험과 아직 검증할 가설

### 시작 구간의 편향 학습률

첫 실험은 AdamW와 lr0=0.0001을 명시했지만 warmup_bias_lr=0.1을 그대로 사용했다. 시작 값이 본 학습률의 1,000배다. 설치된 Ultralytics 8.4.146의 BaseTrainer.build_optimizer는 optimizer=auto일 때만 warmup_bias_lr를 0으로 바꾼다. 명시적 AdamW는 이 보정을 받지 않는다. 첫 에포크의 큰 하락과 부합하는 원인 후보지만, 시간적 동시성만으로 단일 원인을 확정할 수는 없다.

같은 원본 YOLO26s 체크포인트, 같은 첫 실험 train/val 목록, 같은 증강·seed·20에포크 학습률 일정에서 warmup_bias_lr만 0으로 바꾸어 첫 에포크를 비교한다. 한 에포크 후 진단을 종료하며 최종 성능을 증명하는 실험으로 취급하지 않는다. 이 진단의 가중치를 확대 모델 시작점으로 사용하지 않는다.

### 기존 학습 분포의 축소

첫 실험은 기존 객체 사진 약 4.7만 장 중 6,444장만 선별했다. 반복 샘플링까지 포함해 신규 출처 비중이 커졌고, bbox 신규 자료는 plastic 비중이 높았다. 원래 물체의 색·모양·배경 다양성을 충분히 재현하지 못했을 수 있다. 구조 검사와 해시 검사는 의미 라벨 전수 검수를 대신하지 못한다.

### 여러 요인의 동시 변경

데이터 분포, 증강, optimizer, 시작 학습률, YOLO26 손실 일정이 함께 바뀌었다. 흐림과 Mosaic 자체가 하락의 원인이라고 단정할 근거는 없다. 초기 실험 도중 20→100에포크로 연장하여 일정도 달라졌다. 이번 본 학습은 처음부터 100에포크 상한을 고정한다.

### 평가와 선택

첫 실험은 신규 run 안에서만 best를 선정했다. 두 번째 실험은 원본 모델의 고정 검증 성능도 비교 기준으로 명시한다. 기존 시험 결과는 이미 열람했으므로 시험 점수를 보고 반복 설정을 고르는 것은 피한다. 설정 선택은 val에 한정하고, 최종 선택 후 시험을 한 번 평가한다. 한국 현장·흐림·수건·코팅지의 별도 미학습 평가 사진은 아직 충분하지 않으며, 기존 시험 성능 상승만으로 이 사례들의 개선을 보장할 수 없다.

## 3. YOLO26m/l 확대 방안

m/l은 YOLO26의 중형/대형 구조다. 공식 검출 COCO 표는 s/m/l에 각각 약 9.5/20.4/24.8M 파라미터와 20.9/68.4/86.8 GFLOPs를 제시한다. 이는 추론용으로 융합된 구조 기준이고, 학습 시 두 검출 헤드를 포함한 파라미터 수와 다르다. 공식 COCO 성능은 이 쓰레기 데이터에서의 성능 보장이 아니다.

s→m/l 또는 YOLO11n-seg→YOLO26m-seg는 모델 구조가 달라 원래 가중치 전체와 optimizer를 그대로 복원할 수 없다. 각 크기의 공식 사전학습 가중치를 기반으로 7개 클래스를 학습한다. 기존 쓰레기 모델은 평가 기준으로 보존한다. 단순한 부분 가중치 복사를 완전한 전이로 표현하지 않는다.

RTX 4060 8GB에서 640, 실제 이미지·7클래스 라벨, AdamW, AMP 조건으로 bbox m/l와 seg m/l를 순차 실측한다. 준비 구간 8스텝을 제외한 24스텝의 처리량과 GPU 최대 할당량을 기록한다. 검증·EMA·저장 비용이 빠진 짧은 측정이며 정확도 비교가 아니다. 메모리 여유와 처리량을 고려해 우선 m을 본 학습 후보로 선택하고, l은 추가 비용 대비 검증 향상을 따로 확인할 후보로 남긴다. 최종 선택은 model_selection.json에 기록한다.

## 4. 데이터 구성 수정

- bbox train 53,103장, seg train 50,180장을 사용한다. 각 과제의 기존 train 전체와 검증된 신규 자료를 포함한다.
- 기존 공통 train 47,054장이 중심이고, 각 과제의 고유 train도 포함하여 원래 다양성을 복원한다. 다른 과제의 val/test를 가져오지 않는다.
- 첫 실험의 목록 반복은 제거한다. 에포크당 같은 경로를 중복 노출하지 않는다. 기존 데이터 자체의 생성 이미지까지 삭제한다는 뜻은 아니다.
- 클래스별 객체 수는 reports/data_manifest.json에 기록한다. bbox plastic 객체 21,080개로 여전히 가장 많으며 완전한 균등 분포라고 주장하지 않는다.
- 배경은 빈 라벨이다. 기존 배경과 직접 검수한 모니터·교실 장면을 유지한다. 대상 객체가 존재하는 장면을 빈 라벨로 바꾸지 않는다.
- 오염과 배출 방법은 라벨 기준이 아니다. 코팅 종이 기반 제품은 paper, 천 수건은 general이며 지역별 배출 안내는 앱에서 처리한다.
- 모든 이미지는 이전에 전수 검증한 640×640 압축 JPEG와 변환 라벨을 참조한다. EXIF/GPS/XMP/ICC/주석 부가정보를 제거한 상태를 유지한다. 추가 원본·모자이크·흐림 파일을 생성하지 않는다.

## 5. 본 학습 설정과 순서

1. YOLO26s 시작 학습률 대조 진단으로 원인 후보를 확인한다.
2. GPU에서 m/l 검출·분할의 실행 가능성과 속도를 순차 실측한다. 진단과 벤치마크도 동시에 실행하지 않는다.
3. 선택한 확대 검출 모델을 학습하고 검증한다.
4. 검출 작업이 종료된 뒤 선택한 확대 분할 모델을 학습한다.

본 학습은 imgsz=640, 최대 100에포크, patience=10, AMP, AdamW, lr0=0.0003, warmup_bias_lr=0, warmup_epochs=3, batch는 메모리 실측으로 결정한다. nbs=64의 기본 누적 업데이트를 사용하되 이것이 실제 batch 64와 완전히 같다는 의미는 아니다. 사전학습된 확대 모델에 새 7클래스 헤드를 학습하므로 기존 7클래스 모델 미세조정의 학습률과 구분한다.

Mosaic 확률은 0.2, 회전 ±5도, 축척 변화 0.15로 낮추고 첫 본 학습에는 추가 흐림/재압축을 넣지 않는다. 640 변환·저장 압축은 그대로 유지된다. 복잡한 추가 증강을 한 번에 늘리기 전에 학습 안정성과 기존 검증 성능을 확보하려는 선택이다. 흐림 보강은 별도 미학습 사례 평가와 함께 후속 한 요인 실험으로 다룬다. dropout은 detect/segment 정규화로 사용하지 않는다.

close_mosaic=10은 최대 일정의 마지막 10에포크에만 적용되므로 조기 종료되면 실행되지 않을 수 있다. 이 한계를 보고하고, 기본 검증 성능이 좋은 후보에 한해서 추가적인 무 Mosaic 미세조정을 별도 run으로 비교할 수 있다. 처음부터 항상 이 단계가 실행된다고 보장하지 않는다.

## 6. 결과 승인 기준과 복구

본 학습의 best.pt는 검증 점수로 선택한다. 원본보다 낮으면 개선 실패로 표시하고 기존 가중치를 유지한다. 전체 점수뿐 아니라 general, paper, vinyl 등 클래스별 하락도 기록한다. 실제 사례 평가가 부족하므로 자동 배포는 하지 않는다. 원본·첫 실험·새 실험 가중치를 분리하며 오류 시 다음 GPU 작업을 시작하지 않는다. 중단 시 새 run의 last.pt에 optimizer가 남아 있으면 이어 학습한다.

학습 데이터가 첫 실험보다 약 5배로 늘고 모델도 커지므로 학습 시간은 길어진다. 짧은 벤치마크로 전체 종료 시각을 확정하지 않고 실제 첫 에포크 완료 후 검증 포함 시간을 보고한다. 100에포크는 상한이며 조기 종료 시 더 짧아진다.

## 7. 모델 크기 실측 및 선택 결과

| 과제 | 모델 | batch | 이미지/초 | 최대 할당 MiB |
|---|---|---:|---:|---:|
| bbox | YOLO26m | 8 | 37.36 | 4407 |
| bbox | YOLO26l | 8 | 30.47 | 5448 |
| seg | YOLO26m | 4 | 22.47 | 2949 |
| seg | YOLO26m | 8 | 23.25 | 5489 |
| seg | YOLO26l | 8 | 21.43 | 6529 |

검출은 YOLO26m batch 8, 분할은 YOLO26m-seg batch 4를 선택했다. seg batch 8은 4보다 약 3.5% 빠르지만 메모리 할당이 약 2.9→5.5GiB로 늘어 작은 batch를 선택했다. 검출 m은 l보다 약 23% 높은 처리량이다. l은 실행 불가능한 모델이 아니라 추가 시간 대비 실제 검증 향상을 아직 확인하지 않은 후보다.

짧은 측정의 학습 스텝 처리량에 전체 train 수를 나눈 추정은 bbox 약 24분/에포크, seg 약 37분/에포크다. 검증·저장 등을 포함하면 더 길어진다. 두 모델이 모두 100회를 채우면 학습 스텝만 약 102시간인 큰 작업이다. 실제 첫 에포크 및 조기 종료 시점에 따라 달라지며, 이전 소형 데이터 전이학습의 6시간 예상은 적용하지 않는다.

## 8. 원인 대조 실험의 실제 결과

| 조건 | 검증 mAP50–95 |
|---|---:|
| 수정 전 원본 YOLO26s | 84.92 |
| 첫 실험 1에포크 | 69.56 |
| 편향 시작 학습률만 0으로 수정, 1에포크 | 66.68 |
| 위 모델의 BN 통계만 원본으로 복원 | 63.52 |

편향 학습률 보정만으로 개선되지 않았고, BN 통계 복원도 악화됐다. 두 요소를 단독 주원인으로 확정하거나 해결 완료라고 주장하지 않는다. 높은 IoU에서의 위치 정확도가 크게 떨어진 현상이며, 학습 분포와 최적화·손실 일정의 복합 영향이 남은 가설이다. 708/708 가중치 항목이 이전 모델에서 로드된 로그를 확인했으므로 전체 가중치 미로드를 원인으로 지목할 근거도 없다.

대조 실험은 시험 자료를 사용하지 않았다. 두 번째 본 학습은 검출 YOLO26m batch 8 후 분할 YOLO26m-seg batch 4로 진행하며, 사전학습 가중치는 각 모델 크기에 맞는 별도 복사본이다. 실제 상태는 reports/state.json, 에포크 실측은 reports/bbox_epochs.json 및 seg_epochs.json에 기록한다.
