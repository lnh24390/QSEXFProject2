# 640 Mosaic 속도 비교 결과

RTX 4060, batch 16, workers 4, AMP, 512장, 첫 에포크 제외 후 2에포크의 학습 스텝 처리량. 같은 과제의 모델/원본 풀은 동일하다. 검출은 복사한 YOLO26s, 분할은 복사한 YOLO11n-seg다.

| 과제 | 내장 Mosaic | 사전 생성 | 미사용 |
|---|---:|---:|---:|
| bbox | 83.38장/초 | 83.40장/초 | 83.16장/초 |
| seg | 124.38장/초 | 129.16장/초 | 129.17장/초 |

검출의 사전 생성 속도 이득은 약 0.03%로 측정 잡음 범위다. 분할은 약 3.84%의 처리량 이득이 관찰되었으나 짧은 단일 실행 결과다. 반복 실행에 대한 신뢰구간을 측정하지 않았으므로 작은 차이를 확정적인 성능 차이로 해석하지 않는다.

사전 생성에는 bbox 5.09초/44.85MB, seg 5.66초/45.16MB가 추가로 들었다(각 512장). 사전 생성된 조합은 고정되어 반복되며 원본 조합을 다시 바꾸려면 재생성이 필요하다. 실제 학습에는 원본별 640 이미지만 두고 내장 Mosaic을 사용한다. 최종 선택: mosaic=0.5, close_mosaic=5.

고정 방식은 내장 Mosaic+identity affine을 한 번 실행해 만든 파일을 사용했다. 두 방식 모두 이후 HSV/좌우반전을 수행한다. 비교 중 회전·이동·스케일은 0으로 고정해 Mosaic만 분리했다. 정식 학습에서는 moderate 설정의 약한 기하 증강을 다시 사용한다.

이번 속도 측정의 최적화기는 SGD였다. 정식 전이학습은 AdamW를 사용하므로 절대 처리량과 메모리는 실제 에포크 로그로 다시 측정한다. 검증·저장·EMA·전체 Trainer 비용을 제외한 짧은 스텝 실측이며 전체 에포크 예상 시간으로 그대로 사용하지 않는다. 속도용으로 업데이트한 가중치는 폐기하고 원래 복사 best.pt에서 새로 시작한다.

정확도 우열은 이 실험으로 알 수 없다. 빠르다는 이유만으로 고정 모자이크를 선택하지 않는다. 독립 평가 자료에서 새 가중치의 클래스별 재현율과 오탐을 확인한다. 원본 개별 사진의 세부가 줄어드는 문제는 내장 Mosaic에도 존재하므로 마지막 5에포크에 끄며 과도한 강도로 설정하지 않는다.
