# 클래스당 10,000장 YOLO 데이터셋

7개 클래스 각각 10,000장을 포함합니다. 이는 train+val+test 합계의 클래스 포함 이미지 수이며 박스 수가 아닙니다. 같은 이미지에 여러 클래스가 있으면 각 클래스 수량에 포함됩니다. 실제 이미지 파일은 59,236장입니다.

640×640 RGB, YOLO 검출 라벨이며 모든 기존 박스를 그대로 보존했습니다.

| ID | 클래스 | 이미지 |
|---:|---|---:|
| 0 | paper | 10,000 |
| 1 | plastic | 10,000 |
| 2 | can | 10,000 |
| 3 | glass | 10,000 |
| 4 | battery | 10,000 |
| 5 | vinyl | 10,000 |
| 6 | general | 10,000 |

`data.yaml`을 학습 설정으로 사용합니다. images/train·val·test와 labels/train·val·test의 같은 이름이 한 쌍입니다. `class_lists`는 각 클래스가 포함된 이미지 경로 목록이며, 학습 라벨은 아닙니다. 클래스별 이미지 복사 폴더는 만들지 않아 여러 클래스가 함께 있는 이미지의 박스를 유지합니다.

선별: 여러 물체가 함께 있는 장면, 같은 물체의 다른 촬영 구도, 배경·크기·거리의 다양성, 제공 박스의 상태를 우선했습니다. 다중 클래스 이미지 8,980장, 박스가 여러 개인 이미지 18,204장입니다. 이 수는 라벨 기준이며 모든 배경 물체를 전수 판독한 수는 아닙니다.

기존 일반쓰레기에서 새로 만든 증강본은 6,988장입니다. Roboflow 배터리 자료 6,197장에도 제공처 증강본이 포함될 수 있습니다. 500·1,000장 세트에서 일반쓰레기 신규 증강본은 제외했습니다.

500 ⊂ 1,000 ⊂ 5,000 ⊂ 10,000 관계이며 공통 이미지의 분할도 동일합니다. 원본 분할을 기본으로 사용하고, 알려진 원본 그룹이나 동일 지각 해시가 다른 분할에 걸치면 같은 분할로 모았습니다. 이는 근사 검사로, 모든 미확인 유사 장면의 누수가 없다는 보증은 아닙니다.

원본 라벨을 재작성한 작업이나 전수 수동 검수는 아닙니다. 10,000장 세트는 battery/general 수량 제약으로 해당 클래스 전체(증강본 및 기존 라벨의 한계 포함)를 사용합니다. 원본 출처·라이선스와 상세 선별 이력은 ../merge_7class_audit/size_subsets_20260909/SUBSETS_REPORT.md를 참고하세요.
