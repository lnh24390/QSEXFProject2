변환 전 후보와 원본은 새 데이터셋에서 정리했다. 휴지통 이동이 실패한 staged_bbox는 외부 work/cleanup_recovery_20260913/staged_bbox에 복구용으로 남아 있으며 학습에 사용하지 않는다. 기존 프로젝트의 두 YOLO 폴더는 보존용이며 실제 학습 경로가 아니다. 출처·라이선스는 sources/reports에 남겼다.

## 폴더 안내

- `staged_bbox`: 기존 bbox 사본 + 신규 반영 후보. 총 62,368장. 검수 중 자료 포함.
- `staged_seg`: 기존 seg 사본 + 신규 반영 후보. 총 62,362장. 검수 중 자료 포함.
- `reviewed_bbox`: 직접 박스 라벨링한 Commons 6장. 독립 평가셋이나 전체 7클래스 학습셋이 아님.
- `raw`: 다운로드 원본 보존.
- `prepared`: EXIF 방향을 정상화한 신규 이미지 19장. 원본 별도 보존.
- `sources`: 수집 성공·실패, 출처 URL, 라이선스·저작자, 원본 COCO 주석.
- `annotations`: 객체별 매핑·변경 이력·육안 검수 기록.
- `legacy_bbox_manifest.jsonl`, `legacy_seg_manifest.jsonl`: 전체 기존 이미지·객체의 출처와 검수 상태.
- `policy/재질_품목_라벨링_기준.md`: 최종 클래스 기준.
- `reports/검수_미리보기.html`: 새 bbox 후보 132장의 박스·출처를 확인하는 화면.
- `reports/validation.json`: 최종 파일·좌표·변경 이력 검증 결과.
- `scripts`: 재현 가능한 수집·변환·검증 코드.

staged 설정 파일은 `STAGED_NOT_FULLY_REVIEWED.yaml`입니다. `data.yaml`이라는 이름의 검수 완료본으로 제공하지 않았습니다. 기존 원본 이미지와 연결된 **하드링크**를 사용해 중복 디스크 사용을 줄였습니다. 라벨은 독립 사본입니다. 이미지 내용을 수정할 때는 새 파일로 저장해야 원본에 영향을 주지 않습니다.

## 사용 전 알아야 할 범위

기존 bbox·seg는 클래스 번호와 val/test 분할이 서로 다릅니다. 각 체크포인트와 같은 과제의 사본만 연결합니다. 신규 사진은 train 후보로만 넣었으며, 기존 val/test를 train으로 옮기지 않았습니다. 원래 정답으로 평가한 옛 점수와 수정된 정답으로 평가한 새 점수를 모델 개선량으로 직접 비교하지 않습니다.

현재 수집분에는 국내 실제 쓰레기의 클래스·품목·색·찌그러짐·반사 조건이 모두 충분히 갖춰져 있지 않습니다. 특히 **신규 TACO 반영분에는 battery가 없습니다.** 한국 소주병 등 일부 사례는 있지만 국내 촬영·국내 폐기 장면 전체를 대표하는 자료로 볼 수 없습니다. 기존 데이터의 전수 육안 재분류, 모호한 복합재질 검수, 국내 클래스별 부족 조건 수집은 남아 있습니다.

AI Hub 71362는 국내 자료 확장 후보로 확인했지만 로그인·이용 절차가 필요하고 사용자가 현재 내려받은 자료가 없다고 답했습니다. 이번 폴더에 AI Hub 신규 자료가 있다고 집계하지 않습니다. 수집 서버의 요청 제한 등으로 실패한 TACO 376건과 Commons 39건은 다운로드 완료에 포함하지 않았으며 실패 기록을 보존했습니다.

재질 인식 모델의 개선 목표와 약 12,000~20,000장 첫 전이학습 예산 제안은 프로젝트 루트 `04_results/project_analysis/학습_개선전략_20260913.md`에 갱신했습니다. 이 수량은 성능 보장이 아닙니다. 현재 추가 수집분만으로 충분히 개선될 것이라고 주장하지 않으며, 이번에는 모델 학습을 실행하지 않았습니다.

최신 학습 상한은 100에포크, patience=10이다. 검출은 완료된 2에포크의 last.pt와 optimizer 상태를 복원해 이어간다. 학습률 감소 일정도 100에포크 기준으로 연장된다.
