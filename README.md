## 텐서플로우와 파이토치 차이
GPU 사용 여부 CUDA연동
텐서플로우보다 파이토치가 GPU 호환성이 좋음  
GPU는 병렬연산처리로 연산이 빠르고 CPU는 한번에 처리할 수 있는 데이터가 적기에 GPU로 데이터 처리가 용이한 Pytorch사용  
CPU만으로 빠른속도 학습 시도시 Overflow 발생가능성이 있음 그리고 데이터 처리량이 방대해질수록 학습시간이 오래걸릴 수 밖에 없음 그러므로  
안전하면서 빠른학습을 위해 pytorch를 사용
## conf(confidence (신뢰도))=0.25에서 0.35로 올린 까닭
원인 : 객체 인식률 저조  
기대 : 객체 인식률 향상  
결과 : 객체 인식률 향상

* 두 값이 다르게 설정된 이유  
   
두 값이 다르게 설정된 이유는 추론(Prediction)을 실행하는 '환경'이 서로 다르기 때문입니다.

conf=0.25 (단일 이미지 테스트용):
코드의 4번 검증 단계에서 저장된 깔끔한 사진 한 장을 불러와 시각화해 볼 때 쓰입니다. 정지된 이미지는 화질이 좋고 흔들림이 없기 때문에, 기준점을 0.25로 살짝 낮게 잡아 모델이 잡아내는 객체들을 최대한 폭넓게 확인해 보려는 의도입니다.

CONFIDENCE = 0.35 (실시간 웹캠 추론용):
코드의 5번 웹캠 단계에서 쓰입니다. 웹캠 영상은 조명도 계속 변하고, 손이나 물체가 움직이면서 잔상(Motion Blur)이 생기며, 배경 노이즈도 많습니다. 만약 웹캠에서도 기준을 0.25로 낮게 잡으면 아무것도 없는 허공에 박스가 번쩍거리는 '오탐지(False Positive)'가 심해져 화면이 지저분해집니다. 그래서 실시간 환경에서는 기준을 0.35로 살짝 높여서 확실한 것만 네모 박스를 치도록 한 것 입니다.
