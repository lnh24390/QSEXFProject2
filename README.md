## 텐서플로우와 파이토치 차이
GPU 사용 여부 CUDA연동
텐서플로우보다 파이토치가 GPU 호환성이 좋음  
GPU는 병렬연산처리로 연산이 빠르고 CPU는 한번에 처리할 수 있는 데이터가 적기에 GPU로 데이터 처리가 용이한 Pytorch사용  
CPU만으로 빠른속도 학습 시도시 Overflow 발생가능성이 있음 그리고 데이터 처리량이 방대해질수록 학습시간이 오래걸릴 수 밖에 없음 그러므로  
안전하면서 빠른학습을 위해 pytorch를 사용

YOLO 모델(Ultralytics 등) 추론 결과나 로그에 출력되는 0.35는 신뢰도 임계값(conf=0.25)과 다른 지표입니다. 보통 다음 세 가지 원인 중 하나입니다.

1. 추론 시간(Inference Speed, ms)
콘솔 로그에 출력되는 image 1/1 ...: 640x640 ... 0.35ms 형태의 숫자라면, 신뢰도가 아니라 GPU 추론 연산에 걸린 시간(밀리초, ms)입니다.

2. 박스에 표시된 개별 객체 신뢰도 점수
conf=0.25로 설정했다면 모델은 신뢰도가 0.25 이상인 객체만 필터링하여 화면에 표시합니다. 바운딩 박스 옆에 라벨과 함께 표시된 0.35(또는 35%)는 모델이 해당 객체를 탐지한 실제 예측 확률(Confidence Score)입니다. 0.25 기준을 통과했기 때문에 정상 출력된 것입니다.

3. 다른 하이퍼파라미터(IoU / NMS 임계값)
설정 코드나 인자 중 iou=0.35 또는 NMS(Non-Maximum Suppression) 임계값이 함께 지정되어 콘솔 요약 정보에 출력되고 있을 수 있습니다.
